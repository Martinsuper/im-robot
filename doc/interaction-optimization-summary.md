# 桌面宠物交互逻辑优化实施总结

## 实施日期
2026-06-13

## 优化目标
解决手势冲突、功能重复、定位问题和反馈缺失等交互逻辑问题。

---

## 已完成的优化

### 1. ✅ 优化长按定时器逻辑 (Task #1)

**问题**: 长按定时器在 `onMouseDown` 中启动，只在超过拖动阈值后才清除，可能导致同时触发长按和拖动。

**解决方案**:
- 在 `onMouseDown` 中立即清除旧的长按定时器，避免与新的拖动冲突
- 在 `onMouseMove` 中超过拖动阈值时立即清除长按定时器和状态

**修改文件**:
- `src/features/pet/hooks/usePetDrag.ts`

---

### 2. ✅ 移除双击触发休息/唤醒逻辑 (Task #2)

**问题**: 双击与拖动容易冲突，用户可能困惑。

**解决方案**:
- 移除 `PetWindow.tsx` 中的 `onDoubleClick` 处理
- 休息/唤醒功能统一通过长按快捷菜单访问

**修改文件**:
- `src/features/pet/PetWindow.tsx`

---

### 3. ✅ 移除底部操作栏，统一功能入口 (Task #3)

**问题**: 右键菜单和底部操作栏功能高度重叠，用户不知道该用哪个。

**解决方案**:
- 移除底部操作栏 `<div className="pet-actions">`
- 所有功能统一通过"长按快捷菜单"访问
- 减少视觉干扰，让宠物精灵更突出

**修改文件**:
- `src/features/pet/PetWindow.tsx`

---

### 4. ✅ 优化右键菜单定位 (Task #4)

**问题**: 右键菜单使用 `clientX/clientY` 定位，在透明窗口中可能位置偏移。

**解决方案**:
- 使用 `petRef.current?.getBoundingClientRect()` 计算菜单位置
- 固定在宠物精灵下方居中显示
- 添加 CSS `transform: translateX(-50%)` 确保水平居中
- 添加 `max-width: calc(100vw - 16px)` 确保不超出窗口边界

**修改文件**:
- `src/features/pet/PetWindow.tsx`
- `src/App.css`

---

### 5. ✅ 增强视觉反馈 (Task #5)

**问题**: 缺少清晰的视觉提示告诉用户当前状态。

**解决方案**:

#### 5.1 添加长按进度环动画
- 在 `usePetDrag` hook 中添加 `isLongPressing` 状态
- 添加 `onLongPressStart` 和 `onLongPressEnd` 回调
- 在 CSS 中添加 `.pet.is-long-pressing::before` 样式，显示旋转进度环

#### 5.2 添加悬停提示
- 在 CSS 中添加 `.pet::after` 样式，显示"点击对话"提示
- 使用 `@keyframes pet-hover-hint` 实现 2 秒后淡出效果

#### 5.3 增强拖动反馈
- 在 `.pet.is-dragging` 中添加 `opacity: 0.85`，拖动时显示半透明效果

#### 5.4 添加"换模型"功能到快捷菜单
- 将底部操作栏的"换模型/官方"功能添加到右键菜单
- 确保所有功能都可以通过长按访问

**修改文件**:
- `src/features/pet/hooks/usePetDrag.ts`
- `src/features/pet/PetWindow.tsx`
- `src/App.css`

## 手势系统优化总结

### 优化前的手势
- 点击 = 打开气泡对话
- 双击 = 休息/唤醒 ❌ (已移除)
- 长按 (520ms) = 显示右键菜单
- 拖动 = 移动窗口
- 轻扫 = 抚摸宠物 ❌ (保留但优先级降低)

### 优化后的手势
- **点击** = 打开气泡对话 ✅
- **拖动** = 移动窗口 ✅ (优先级最高)
- **长按** = 显示快捷菜单 ✅ (带进度环反馈)
- **轻扫** = 抚摸宠物 ✅ (保留，但不常用)

### 手势优先级
1. **拖动** (最高优先级) - 超过 4px 立即触发
2. **长按** (中等优先级) - 520ms 后触发，带进度环
3. **点击** (最低优先级) - 无移动时触发

## 视觉反馈增强

### 1. 悬停提示
- 鼠标悬停时显示"点击对话"提示
- 2 秒后自动淡出
- 避免视觉干扰

### 2. 长按进度环
- 按住 520ms 期间显示旋转进度环
- 进度环完成时表示菜单即将打开
- 提供清晰的等待反馈

### 3. 拖动反馈
- 拖动时宠物显示半透明效果 (opacity: 0.85)
- 光标变为 `grabbing`
- 宠物略微变形 (scale: 1.08, 0.96)

### 4. 光标样式
- 悬停: `cursor: grab` (提示可拖动)
- 拖动: `cursor: grabbing` (提示正在拖动)
- 按钮: `cursor: pointer` (提示可点击)

## 风险与缓解

### 风险 1: 用户可能不习惯长按触发菜单
**缓解**: 
- 保留系统托盘作为备选入口
- 添加悬停提示"点击对话"引导用户
- 进度环提供清晰的等待反馈

### 风险 2: 移除双击可能让部分用户失望
**缓解**:
- 休息/唤醒功能仍可通过长按菜单访问
- 未来可在设置中添加"高级手势"选项

### 风险 3: 长按 520ms 可能过长或过短
**缓解**:
- 当前 520ms 是行业标准和iOS的默认值
- 未来可在设置中允许自定义 (300ms-800ms)
