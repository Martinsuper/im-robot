# Piko 1.2.24

## 界面与交互

- 修复窄窗口导航栏横向溢出及会话标题挤压，补充图标导航提示。
- 调整窄窗口和短窗口的日历间距，让当天日程更早进入视野。
- 日程完成与删除按钮保持可见，扩大操作区域，改善辅助文字和键盘焦点的可读性。

## 稳定性与构建

- 统一事件订阅清理工具，补充共享基础设施依赖边界检查。
- 修复持久化状态并发初始化及事件订阅失败后的重试，保留加载期间收到的较新状态。
- 构建脚本只收集正式 Piko.app，避免混入本地验收应用。
- 将 ctutils 更新至 0.4.4，修复 RUSTSEC-2026-0385 安全公告，解除上版发布构建的审计阻断。

## 验证

- 本地完整桌面端自动化验收 17 个阶段通过，包含 321 项前端测试、140 项 E2E、356 项 Rust 单元测试和 1 项集成测试，以及 Agent、原生桥接、依赖审计和 macOS 应用包检查。
- macOS Apple Silicon 安装包已在本机完成安装和启动验证。
- 各平台正式安装包由本次 Release Build 工作流构建并上传。
