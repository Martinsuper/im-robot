# Piko v1.3.1

- 新增半自动更新：启动稍后与每天各联网检查一次 GitHub Releases，发现新版本时在面板顶部显示横幅并发送系统通知。
- 更新横幅支持「查看详情」跳转设置页下载，也支持「跳过此版本」——该版本的自动提醒不再出现，手动检查更新不受影响。
- 「关于与更新」新增「自动检查更新」开关（默认开启），可随时关闭定时检查。
- 下载与安装流程保持不变：SHA-256 校验通过后在面板内下载，手动打开 DMG 完成安装。

## 从旧版升级

自动检查仅访问 GitHub Releases 接口；下载安装包始终校验发布方提供的 SHA-256 值后才保留。macOS 安装包采用 ad-hoc 签名，尚未经过 Apple 公证。
