# Piko 1.2.23

## 工作区与日历

- 采用新的浅色三栏界面：左侧导航与会话列表、中间对话、右侧日历和当天安排。
- 月历通过圆点概览每天的事项数量，支持切换月份、选择日期和一键回到今天。
- 选择日期后联动显示当天事项，快速添加默认使用所选日期；跨天日程会显示在覆盖的日期中。
- 保留事项完成、删除、冲突提示、专注计时和系统日历同步入口。

## 交互修复

- 修复原生窗口调整大小时，切换记录或设置可能丢失导航请求的问题。
- 窄窗口继续提供会话切换与键盘导航，工作区宽度与拖拽手柄显示保持一致。
- 切换工作区保持聊天草稿，并调整相关浏览器测试以匹配新的导航和对话标题。

## 自动化验证

新增月历日期排列、跨年导航、跨天事项边界、选日创建事项、重载后数量更新等测试，并运行前端、Agent、Rust、原生桥接与浏览器回归检查。发布工作流继续在 macOS Apple Silicon、macOS Intel、Windows 和 Linux 构建安装包及校验文件。
