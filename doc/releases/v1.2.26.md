# Piko v1.2.26

- 恢复 ESP32 设备历史会话在最近对话中的展示，完善 Passport 语音交互。
- 更新 macOS 截图实现，并补齐 Windows 测试程序所需的 Common Controls v6 清单。
- 修复最近会话只能关闭、无法实际删除的问题，同时清理聊天记录、任务历史和草稿。
- 删除采用原位两步确认：先点击叉，再点击红色垃圾桶；点击其他位置或按 Esc 取消。删除失败时保留会话并提示原因。
- 模型、MiMo 语音和 Embedding 的 API Key 改为单独保存在本机文件中，不再通过系统钥匙串读取或保存，避免重新安装后反复要求授权。
- 统一 macOS 应用签名和 DMG/APP ZIP 打包流程，验证打包与解压后的签名，并为下载包生成校验值。

## 从旧版升级

本机密钥文件不加密；macOS/Linux 权限为仅当前用户读写（0600），不包含在数据导出或备份快照中。请勿分享该文件。

旧版钥匙串中的密钥不会被自动读取或删除。升级后若提示未配置密钥，可在设置中重新填写；也可从本版本源码中，在退出 Piko 后运行一次 `python3 scripts/migrate-keychain-credentials.py`，将旧密钥迁移到本机文件。迁移可能需要最后一次系统授权，不覆盖已有本机密钥，且不会显示密钥内容。

macOS 安装包采用 ad-hoc 签名，尚未经过 Apple 公证。
