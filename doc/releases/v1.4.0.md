# Piko v1.4.0

## 委托任务更可靠

- 任务工作区与原始 prompt 持久化到 journal：应用重启后「重新发起」与任务日志回看不再丢失上下文，也不会重复回放工具调用、输出与凭据。
- 定时任务启动失败（配额不足、工作区忙）不再直接失败，而是进入「排队」状态并按 30/60/120/240/300 秒退避自动重试；连续 5 次失败才置为失败并保留最后一次原因。历史记录显示排队徽标，宠物反馈与系统通知同步提示。

## Windows 安全加固

- 新增 Windows 破坏性命令启发式拦截：`del/erase/rd`、`format/diskpart/bcdedit`、`Remove-Item/Clear-Content`、`reg/sc/net/taskkill/schtasks/icacls/takeown` 等高危命令及盘符、`%SystemRoot%` 路径操作会被标记拦截，侧车进程同时上报黄旗提示。
- 升级 wasmtime 等依赖，修复 WASI 文件系统沙箱逃逸（高危）等 12 项安全通告；`cargo audit` 已纳入 CI 硬门禁。

## 语音助手

- 常驻语音助手新增唤醒词检测：在设置页可开启语音助手并配置唤醒词与唤醒分词，状态与手动触发均可通过面板查看。

## 界面与体验

- 气泡窗口（BubbleWindow）拆分为状态 hooks 与表现组件，渲染路径更清晰，为后续对话界面迭代打底。

## 内部质量

- 新增 stream_chat HTTP 全链路集成测试（SSE 流式、中途取消、非 200、工具调用回传、截断流）与更新包下载管线测试（校验和、篡改、中断恢复）。

## 从旧版升级

更新检查仅访问 GitHub Releases 接口；下载安装包始终校验发布方提供的 SHA-256 值后才保留。macOS 安装包采用 ad-hoc 签名，尚未经过 Apple 公证。
