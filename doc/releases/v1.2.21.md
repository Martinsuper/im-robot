# Piko 1.2.21

## 日常知识与记忆

- 知识库优先展示从使用中积累的项目事实、方法和操作经验；文件导入移至可选参考资料。
- 每日整理有原文依据的明确候选，跳过重复并归档过期内容。自动收录可关闭；检测到的敏感信息、疑似更正与同名冲突留待确认，不自动覆盖旧知识。
- 维护状态、上次结果和下次运行时间可见，支持立即整理、查看来源与修订。
- 自动收录采用事务写入，并与手动确认、拒绝协调，避免重复收录或中断导致候选丢失。
- 重算近期权重不再改写内容更新时间；置顶记忆不再因过期而隐藏。

自动维护在应用运行且自动提取开启时执行。未配置 AI 时，规则提取的候选仍需确认。当前冲突检查采用保守规则，不能识别所有语义冲突。

## 悬浮角色与设置

- 悬浮角色缩小约四分之一；松手、惯性结束后按可见角色区域吸附附近屏幕边缘。
- 快速连续拖动会丢弃过时移动请求，多屏菜单栏和 Dock 空隙不再回退到第一块屏幕。
- 清理重复权限展示和开发诊断入口，语音设置归入 AI 与对话，通知测试与权限复查收进通知排查。
- 文件同步与备份移入折叠入口，系统配置分组改为“系统与数据”。

## 发布修复

- 原生验证任务先安装 Agent SDK 测试依赖，修复 1.2.20 在 Windows、Linux 与 macOS 打包运行时测试阶段失败的问题。
- 同步发布版本时一并更新 npm 锁文件中的根包版本。
