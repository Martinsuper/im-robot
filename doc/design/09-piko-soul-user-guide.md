# 人格、主动消息与共同历史

主动消息的全局开关默认关闭。新安装在开启全局开关后仅预选“任务跟进”，其他类别、情绪、共同历史及人格演化需要单独开启。已有设置不会被升级过程自动改写。

## 人格和情绪

设置中可以编辑背景、语气、在意的事、立场和表达偏好。手动设置优先于确认过的演化，每一轮使用固定快照，下一轮读取更新。人格与情绪都不能改变工具权限或只读限制。

情绪默认关闭。开启从新基准开始，关闭会清零。它只影响表达与空闲表情，任务确认、执行、报错、休息和直接互动优先；没有对应动画时使用原动画。取消任务或离开不会产生负面事件。

## 主动消息

任务跟进、话题回访、问候、里程碑、模式观察、小话、产出观察和桌面观察可分别开关或清理。所有类别共享每天最多三条、至少两小时间隔，活动未知、输入、执行任务、等待确认、隐藏精灵及免打扰期间会延后或撤回。开关恢复不补发关闭期间的旧事件。

连续可见二十秒无回应才算忽略。手动关闭与忽略分开记录。连续三次忽略后，该类别间隔加倍、日额度减半且至少为一；回应或七天无新增忽略后恢复。清理消息不会返还已经消费的额度。

“不要说话”“暂停主动消息”会暂停；“恢复主动消息”可恢复。引用别人说过的话或举例不会自动当作这些指令。系统通知权限只在设置中由你主动申请；没有权限仍可使用气泡，不会在后台反复请求。

## 话题回访

计划先作为候选在记忆中心审核，明确日期按原始基准和时区显示，模糊日期保持未排期。批准后可完成、取消或改期；归档话题不会自动成为长期记忆。

启用回访后，已确认且有日期的话题在区间结束后七天内可被跟进。回应“完成了”“取消了”或“改到2026-11-02”等明确表达只生成变更候选，仍需在记忆中心批准。“还没”保持原状，含糊或多个话题的回答先澄清。

## 系统通知

macOS 的任务跟进可以同时使用系统通知。在设置中点击“授权任务系统通知”后，才会申请权限；未授权时仍可使用气泡，后台投递不会反复申请。其他平台目前使用气泡。

专注模式或屏幕共享可能让系统静音横幅。点击屏幕右上角的日期时间可打开通知中心，在通知仍有效时点击正文，会回到同一条任务来源，不会自动续跑任务。消息被关闭、忽略或撤回后，对应系统通知也会移除。应用不会自动修改专注模式或共享屏幕通知设置。

## 共同历史、称呼和演化

共同历史只记录开启后的最小事实，例如任务运行结束、主动消息被回应、明确道谢、收藏产出和共同记录满一周。共同天数按自然日计算，不是连续使用积分。解锁的称呼只是可选表达，不影响能力，也不会自动选中。

演化默认关闭。有限的语气或口头禅偏好至少在三个不同会话明确表达才生成候选，每字段七天最多一次，确认后才生效。例如“请简洁一点”“请热情一点”“口头禅用一步一步来”。拒绝的相同证据不会重复提议。

版本列表可查看内容并回退。回退创建新版本、保留你的手动覆盖并暂停后续演化；需要继续接受提议时，可明确关闭再开启演化。最多保留最近五十个版本。

## 产出与日程

产出观察默认关闭。原生 HTML 预览连续前台可见一分钟或明确收藏，可生成低频的本地消息。只说明这些行为，不把它们说成“你满意”或“页面质量很好”。不调用模型生成主动评价，也不自动写入观点。

日程确认草稿若存在时间重叠、批量总时长超过八小时或超过六项，会附一条温和建议。它不阻塞创建，也不代替原有权限确认。

清理和来源删除会撤回相关候选与消息。全部清空会关闭相关开关并建立新基准；保留少量不含正文的去重、额度与冷却凭据，防止旧记录重建和额外投递。

## 桌面观察与自主聊天

在「人格与主动消息」中开启全局主动消息开关，并单独开启「桌面观察」。新安装及升级均不会自动开启。它使用已配置的支持图片的模型；macOS 需要在系统设置中授予 Piko 屏幕录制权限，后台不会弹出授权窗口。

Piko 会在前台窗口稳定且停止输入后，读取当前窗口截图和标题，结合角色、最近三轮会话及近期主动话题，请模型决定沉默、做一个无声动作或说一句话。启用桌面观察时，模板小话不再生成。观察是定期、按需发生的，不是持续录屏。

安静、自然、活跃档位的最短检查间隔分别为 20、10、5 分钟，每天最多 12 次检查，发言仍共享每天三条、至少两小时间隔。可以按应用名称排除窗口；会议、游戏、Piko 自身、锁屏、任务执行和免打扰期间跳过。暂停主动感知或主动消息均会停止观察。

当前窗口截图会发送给你配置的模型服务，遵循该服务的数据处理政策。截图不写入磁盘或长期记忆；生成的开场白和缩略指纹只保留在进程内的有限缓存。投递前再次核对窗口及画面，变化后撤回过时评论；重启不恢复旧的桌面观察消息。用户接话时向对话模型提供先前的开场白，并明确标注它不代表当前画面。模型的观察决策没有工具调用权限。

观察模型可以独立填写，留空则沿用普通聊天模型。「测试图片理解」只发送自动生成的数字图片，不读取桌面，也不会保存模型或开启观察。它检查模型是否真的识别图片，而不只是连接成功。设置页同时显示屏幕录制权限、当前观察模型、今日剩余检查次数和上次检查错误。
