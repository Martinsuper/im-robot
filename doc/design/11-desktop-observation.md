# 桌面观察与自主聊天（首版实现）

## 行为链路

`desktop-observation` 受后台 Supervisor 管理，每 15 秒采样可用性与窗口身份。必须开启 Soul 全局开关及 `desktop_observation` 类别，且前台窗口稳定 30 秒、键盘停止输入至少 5 秒，才能进入定期检查。最短间隔为安静 20 / 自然 10 / 活跃 5 分钟；检查预算每天最多 12 次，保存于 SQLite，重启或修改偏好不返还预算。

只读取前台窗口，不读取整屏，也不注入输入或操作应用。macOS 沿用 xcap 的系统窗口层级顺序，在前台应用的窗口中取最靠前的窗口；不自动申请屏幕录制权限。缺少权限或无法识别前台窗口时跳过。

窗口截图按比例缩小到 1024×768 内，结合窗口标题、当前角色、最多三轮会话（每段截断 400 字）与最近六条主动话题，使用用户当前配置的 OpenAI Compatible / Anthropic / Gemini 模型进行图片判断。

## 决策与投递

模型严格返回 `silent`、`gesture`、`speak` 三种 JSON 决策。只有 `speak` 可以携带 `message` 和 `topic`；消息最多 120 字，拒绝未知字段和动作。桌面数据明确标注为不可信材料；本次调用不提供工具。无声动作映射现有 `AmbientNudge`。

发送前、结果返回后、消息投递前都检查开关、活动状态与当前窗口。结果返回后及投递前重新比较低分辨率指纹，内容变化时丢弃。消息有效期为 90 秒，共享现有每日三条、两小时间隔、连续忽略退避、回执和去重账本。启用桌面观察时暂停模板小话生产。

模型短句不写入模板表，使用有限进程缓存解析。接话沿用 `proactiveMessageId`，在 Agent prompt 中补充原开场白，标注为历史对话数据。重启后没有缓存的桌面消息不可恢复，调度器撤销其账本状态。

## 设置与存储

独立类别开关默认关闭，排除应用按名称不区分大小写匹配；会议、游戏与自身窗口自动跳过。偏好设置使用 revision CAS，变更后撤销已有桌面消息。清理类别或全部数据同时清除进程缓存；清理不恢复已消耗额度。

Soul schema v5 扩展消息类别 CHECK 约束，迁移保留旧消息全部列和状态；新增 `soul_desktop_control` 保存频率、应用排除与观察预算。截图、窗口标题、模型原始响应不持久化；消息账本仅记录身份、来源、时间窗和投递状态。

## 首版边界

桌面理解依赖截图与窗口标题，尚未接入 Accessibility 文本提取。需要支持图片的模型；供应商错误记录为不含桌面内容的通用错误码，按检查间隔重试。重复画面跳过模型请求。前台窗口识别与截图可用性依赖平台，无法观测时保持安静。会议网页的识别除应用类别外也使用标题提示，并不能识别所有网页会议。

## 验证

后端测试覆盖三态决策、未知字段拒绝、三种服务的图片请求体、指纹比较、默认关闭与暂停、持久化预算与版本冲突、忽略退避、消息冷却、应用排除以及 v4 → v5 数据迁移。前端测试覆盖偏好保存、排除列表处理、读取失败和版本冲突；保留气泡消息恢复与接话回归测试。

## 原生联调与诊断补充

Soul schema v6 增加独立观察模型 `model` 字段，留空沿用普通聊天模型；升级保留观察预算、频率和应用排除设置。普通聊天模型不会因选择观察模型而改变。

设置页每五秒读取观察状态，展示类别是否启用、当前进程的屏幕录制权限、实际观察模型、当天剩余检查次数和后台最近错误。模型服务拒绝图片、无法连接、决策 JSON 无效等错误有对应提示。

「测试图片理解」只向所选模型发送本地生成的随机四位数字 PNG，不读取桌面、角色或对话历史；必须正确返回图片中的数字才判定通过。测试不保存草稿模型，不开启桌面观察，不消费观察检查预算。后端阻止并发测试，并在请求结束或取消时释放占用。

原生应用联调已确认：现有 `deepseek-flash2` 未正确识别数字测试图片；`gpt-6.1-sol` 在同一配置网关通过测试。该结论针对当前网关及本次测试，不代表供应商所有同名模型的能力。真实桌面观察还需要用户单独确认后台访问并授予系统屏幕录制权限。

原生验收注意：macOS 可能保留旧构建的 TCC 代码签名记录，系统开关开启并不保证当前进程已授权。应以应用内权限状态为准；必要时在系统设置移除旧 Piko 条目、重新添加当前安装路径，并重启进程。更新本机应用前已保留旧应用及 v6 前数据库、设置备份。

自动化工具的后台编辑与窗口 Raise 不一定改变系统前台应用。手动验收应让测试文稿真实处于前台；`focused_window_metadata_probe` 是默认忽略的原生诊断测试，只输出当前前台应用元数据、空闲秒数和锁屏状态，不截图。


### 单次发言测试

设置页“测试发言”仅在主动观察已启用时可启动（IPC 限 panel）。只对下一次符合采集条件的观察要求模型返回 speak；正常自主观察提示词和用户设置不变。测试可跳过观察间隔及重复画面过滤，仍需稳定窗口、活动门控、录屏权限、每日模型预算和共享发言配额。测试指令仅存在内存，重启不恢复。生成的话语仍走场景复核、短期缓存、主动消息队列和正常气泡投递。
