# Piko 插件、素材与质量设计

## 1. 范围

本篇合并插件架构、日程工具、精灵素材工作流、冒烟清单、验证报告，以及性能优化相关内容。

## 2. 目标

- 让工具能力有统一的扩展方式。
- 让素材制作有统一的输入输出规范。
- 让验证与性能问题有统一的检查入口。

## 3. 插件与工具

| 方向 | 说明 |
| --- | --- |
| 内置插件 | 日程、工具调用、协作能力 |
| 外部插件 | 未来扩展的受控入口 |
| Manifest | 描述权限、能力、版本和依赖 |

插件扩展必须遵守：

- 白名单入口。
- 明确权限。
- 可审计。
- 可关闭。

## 4. 素材工作流

精灵图、图标和外观资源要有统一规格、命名和导出流程，避免资源在不同模块里各自为政。

## 5. 质量与验证

- 冒烟清单用于快速确认主流程可用。
- 自动化验证报告用于记录回归与修复。
- 性能优化只针对真实瓶颈，不要过早复杂化。

## 6. 实施建议

1. 先把素材和插件边界说清楚。
2. 再把验证和性能监控接进来。
3. 之后再考虑外部生态扩展。
