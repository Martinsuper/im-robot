# 聊天与主面板合并（第一版）

## 决策

以 `bubble` 作为唯一聊天与业务工作区窗口，不再创建独立 `panel` WebView。
`open_panel` 保留 IPC 兼容性，但改为显示 bubble 并发送 `workspace-open`。
顶部名称菜单只负责导航，不与标题栏拖动混用。菜单选择今天、记录、设置后展开右侧内容。

## 状态与布局

- 聊天组件始终挂载；展开、切换、收起不会取消任务或清空输入。
- 工作区首次访问栏目时加载，之后通过 hidden 保留表单、筛选和独立滚动容器。
- 本地存储记住最近栏目，不自动恢复展开，以免每次快速聊天都变成大窗口。
- 原生窗口展开时按当前显示器工作区限制尺寸和位置；收起恢复展开前尺寸。
- 小于 860px 时使用工作区单页，返回聊天只改变可见性，不卸载会话。
- 数据更新通知改为应用事件，让合并后的工作区持续收到历史、记录、记忆、提醒等变更。
- 聊天和面板使用同一 settingsStore，避免同一窗口内设置副本漂移。
- workspace-ready 握手重放 WebView 初始化前的面板请求。

## 第一版不包含

引用卡片、AI 自动导航、左右宽度拖动、完整历史会话恢复。这些按第二版推进。

## 验证

单元测试覆盖显示器边界与原生尺寸恢复；浏览器回归覆盖菜单、双栏、窄屏返回、草稿和栏目保留。
打包原生端还需人工验证多显示器、屏幕边界、系统托盘、首次引导和真实流式回复。

2026-10-22 开发验证结果：

- 前端单元测试：49 个文件，305 项通过（包含切换工作区时流式事件继续到达、未发送输入保留）。
- 浏览器针对性回归：31 项通过，涵盖工作区、面板、记录、设置与模型配置。
- Rust 单元测试：344 项通过，4 项显式忽略的原生/真实模型验收测试未运行。
- TypeScript / Vite 构建、ESLint、Rust 编译与格式检查通过。
- 架构边界与翻译键检查通过；Rust 第三方 xcap 仍有既有废弃 API 警告。

## 发布回归修正

完整浏览器回归额外发现：记录操作菜单的 Escape 事件会冒泡收起工作区；旧测试仍寻找独立面板的「开始对话」，双栏下全页按钮定位还会匹配聊天按钮。
修正版阻止菜单 Escape 冒泡，将返回聊天按钮保持为至少 36px 点击区域，并把相关测试定位限定在工作区内。已推送的 v1.2.17 标签保留，修正版使用 v1.2.18。
