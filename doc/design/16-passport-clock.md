# Passport 时钟表盘（随身表盘时钟复刻）

日期：2026-10-24。状态：设计定稿，未实施。与 [万年历设计](15-passport-calendar.md) 并列，可独立实施。

## 背景与参考

为 Piko Passport 固件新增时钟页面，提供多款可切换表盘，作为桌面/随身的看时间入口。效果对标固件合集中的 **随身表盘时钟**（ID 1322）：五款表盘随心切换、联网自动校时、亮度调节、常亮或自动息屏。

该 ID 固件无源码，本设计按其封面与描述复刻交互与外观；实现层参考有源码的同类项目：

- **赛博朋克时钟**（ID 138，[AP_CyberClock](https://github.com/Y2Lin/AP_CyberClock)）：数字大字表盘渲染、秒级动画、数据线对时思路。
- **逆行怀表**（ID 1303，[reverse-pocket-watch-ai-passport](https://github.com/jonwong0882-source/reverse-pocket-watch-ai-passport)）：线条绘制指针表盘的刷新策略。
- **世界时钟**（ID 139，[pax-zhang/ai-passport demo/dial](https://github.com/pax-zhang/ai-passport/tree/demo/dial)）：多表盘框架与主题切换。
- **天气时钟固件**（ID 1，[gitee.com/WrengCon/ai-passport](https://gitee.com/WrengCon/ai-passport)）：ESP-IDF 5.5 + LVGL + SNTP 对时基线，与本仓库技术栈一致。

## 功能范围

一期做表盘本体。2026-10-25 用户选定卡西欧段码款并移除太空人方案，单表盘交付，天气二期：

| 功能 | 分期 | 说明 |
|------|------|------|
| 表盘亮度调节（长按上下连调 + 小菜单精调） | 一期 | NVS 记忆档位；后续若新增表盘，上下键恢复切表盘职能 |
| 机械数显表盘（Casio 段码液晶仿造，2026-10-25 丰富版 v2 定稿） | 一期 | 整屏作为段码 LCD：程序绘制 7 段码数字（lv_line 粗线段，未点亮段 9% 残影）、冒号每秒闪动、星期行当日反白、秒数独立小位；另含五块本地内容——段码月相盘（朔望月算法）、农历/节气中文条（复用 piko_lunar，节气或节日替换农历日）、WT 双时区行（默认 UTC）、5 段电量条、周数/年进度（WK+D）；右下温度位带段码边框留给二期天气；段码整体 6° 斜切（正宗卡西欧体例）；WT 行上下加字段分隔细线。默认表盘 |
| 模拟指针表盘 | 一期 | `lv_line`/canvas **线条绘制**时分秒针 + 刻度，秒针一秒一跳；不用图片软件旋转（C3 无 FPU，代价高） |
| 极简数字表盘 | 一期 | 黑底白字大数字 + 日期星期 + 电量；若万年历（15 号）已合入则副标题显示农历/节气 |
| 亮度五档调节 | 一期 | 背光 LEDC PWM 占空比表；手势与语音页音量一致 |
| 常亮 / 自动息屏（10 分钟 / 2 分钟） | 一期 | 与语音页息屏策略对齐，录音与播放中不熄屏 |
| 表盘显示天气（网络位置/城市） | 二期 | 需新增 HTTP 客户端 + Open-Meteo 类 API + JSON 解析 + 城市配置整条链路，不阻塞一期 |

与原版的客观差异：本机为彩色 IPS 常亮屏，非反射式 LCD，电池供电下「常亮」耗电明显，息屏策略比原固件更重要；对时复用现有 SNTP（东八区）+ 内部 RTC，断网走时不受影响。

## 菜单与导航

遵守 0.9.0「浏览态 → 进入态」两态模型：**页即菜单项，页面自管页内按键，长按确认是唯一公共出口**。时钟的表盘、亮度、息屏设置全部收在时钟页内，不进全局设置页（设置页保持 Wi-Fi / 电脑配对两项）。

浏览态切页序列（万年历已合入时）：**语音输入 → Piko → 日历 → 时钟 → 设置**，导航药丸五枚；万年历未合入时为语音输入 → Piko → 时钟 → 设置。底部导航为文字药丸（见 15 号文档），非圆点。

时钟页（进入态）按键：

| 操作 | 行为 |
|------|------|
| 短按 上/下 | 亮度五档直接加减，浮出亮度提示条（单表盘期间上下键承担亮度职能） |
| 长按 上/下 | 亮度持续连调，零档最暗；松手即停并写入 NVS |
| 短按 确认 | 呼出时钟小菜单（两行：息屏方式[常亮/10分钟/2分钟]、背光亮度档） |
| 小菜单内 上/下 | 选择行；短按确认改值；长按确认退回表盘 |
| 长按 确认 | 退出时钟页回浏览态 |

设计意图：单表盘期间短按上下直达亮度（高频），长按连调复用音量手势肌肉记忆；息屏等低频项收进两行小菜单，不引入列表控件。进入时钟页即离开语音页，语音任务取消行为与切到连接/输入页一致。

## 实现

- **新模块 `main/piko_clock.c/h`**：表盘注册表（名称 + 渲染函数 + 周期回调），页面只消费注册表，新增表盘不改导航代码。
- **段码数字程序绘制**：7 段码以粗线段矢量绘制（每数字 ≤7 条 `lv_line`，圆角端点），残影用低透明度同形线段，不用点阵字体，flash 增量可忽略。月相盘为双圆叠加遮罩实现，电量条为 5 段矩形，均与段码同色系。
- **背光 PWM**：LEDC 通道绑定背光引脚，五档占空比表，档位与息屏方式写入 NVS；亮度提示浮层复用音量提示的绘制方式。
- **息屏策略**：LVGL 定时器统计空闲，进入息屏时关闭背光而非销毁 UI（唤醒即恢复）；录音、语音播放、操作确认期间抑制息屏，与 0.9.0 电源相关行为对齐。
- **页面接入**：`main.c` 页面枚举、nav dots、`page_locked` 分支；表盘切换时销毁上一表盘对象再建新盘，避免五套 UI 常驻。
- **版本**：合入后版本号递增，不改分区表。

## 资源预算

一期 flash 增量约 50–100 KB（含分段数字字体）；太空人动画另加约 200 KB，默认不编入。运行期为单一表盘常驻，LVGL 对象数十个、堆占用与现有页面同量级，无 PSRAM 压力。

## 验证计划

1. **算法/状态单测（host）**：表盘状态机（切换循环、NVS 保存回滚、亮度档位边界、息屏倒计时与抑制条件）并入 `tests/run.py`。
2. **UI 回归**：`python3 firmware/passport/tests/run.py` 全量通过，五页导航不破坏锁定导航、录音释放与音量逻辑。
3. **实机**：刷写授权与备份流程照旧（固件 README「写入和数据保护」）；实机核对秒针走时、亮度档位实际观感、息屏唤醒不误触、录音中不熄屏，并记录验证文档至 `doc/validation/`。

## 未决与边界

- 天气表盘为二期，需要时另行设计配网与城市配置。
- 时间未同步（SNTP 未生效）时段码显示 --:--，日期星期不点亮，提示「联网后自动校时」。
- 表盘上显示农历依赖 15 号万年历的 `piko_lunar` 模块合入；未合入时极简表盘副标题只显示公历。
- 后续可与万年历合并为「时钟主视图 + 短按确认切换月历」单页，此为导航模型允许的页内演进，不影响本设计按键约定。
