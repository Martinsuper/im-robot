# Piko 桌面助手产品基线与路线图

## 1. 目标

把当前桌面 AI 宠物助手的产品边界、P0 范围、演进节奏和长期路线收拢成一份主文档，避免 baseline、P0、roadmap 多份文档反复重叠。

## 2. 产品基线

当前产品基线可以概括为：

- 桌面精灵常驻。
- 可拖动、可对话、可暂停。
- 支持文件拖入、提醒、面板和基础设置。
- 默认低打扰，用户明确操作优先。

## 3. P0 范围

P0 仍然只保留最核心的闭环：

| 能力 | 说明 |
| --- | --- |
| 桌面精灵 | 透明置顶、拖动、隐藏、恢复 |
| 快速对话 | 文本问答、流式回复、停止生成 |
| 文件交互 | 单个文本文件分析与确认 |
| 截图提问 | 预览后发送 |
| 提醒 | 一次性提醒与列表管理 |
| 权限中心 | 通知、截图、文件访问状态 |
| 个性化 | 命名、主题、活泼度、开机启动 |
| 系统集成 | 托盘、快捷键、更新入口 |
| 隐私 | 清除历史、暂停感知、日志脱敏 |

## 4. 演进阶段

### Phase 1

目标是把用户快速留在产品里：

- 顺手、可见、轻反馈。
- 点击就有回应。
- 对话和拖放不会让用户学习成本过高。

### Phase 2

目标是让陪伴感变强：

- 感知当前场景。
- 让精灵知道用户在忙还是在闲。
- 更自然地处理休息、提醒和轻打扰。

### Phase 3

目标是让记忆和迁移开始真正有用：

- 形成长期偏好。
- 记住用户常做的任务和设置。
- 让不同设备或环境下的体验连续。

### Phase 4

目标是扩展到任务层与平台层：

- 接入更多工具和插件。
- 把有限、确认式任务做扎实。
- 保持安全和可撤销。

## 5. 推荐节奏

| 阶段 | 重点 |
| --- | --- |
| 1 | 基础陪伴和桌面入口 |
| 2 | 场景感知与轻提醒 |
| 3 | 记忆、迁移和持续陪伴 |
| 4 | 任务扩展和平台化 |

## 6. 核心指标

- 首日留存。
- 日活跃交互次数。
- 文件/提醒/对话的实际使用率。
- 用户关闭主动打扰的比例。
- 重复使用率。

## 7. 红线

- 不持续读取屏幕、摄像头或麦克风。
- 不让模型越权执行任意 shell。
- 高风险操作必须先预览再确认。
- 权限申请必须说清楚用途。

## 8. 结论

这份产品路线的核心不是功能清单，而是控制体验节奏：

- 先稳定陪伴感。
- 再增加场景感知。
- 最后才扩大任务边界。
