## 引用检查兼容修复

实际模型经常直接引用证据中的原始 `source` 路径。程序原先只接受 `title`，会误判这类来源合法的引用。现已允许本次实际提供的 `source` 精确匹配，同时继续拒绝未提供的其他路径、错误位置和复合位置格式。新增回归测试通过；Rust 共 340 通过、4 个外部服务测试忽略，评分脚本 9 通过。修复后的 `.app` 已重新构建，通过本地签名校验与内置运行时检查。

本次没有放宽错误行号标准，也没有要求模型重答来替换失败结果。报告保留原始回答，评分脚本单独列出格式异常，避免把“没有被正则解析”当成引用正确。

这是直接 API 回答层测试，没有运行 Pi SDK 工具循环或原生界面交互；代理底层路由和实际模型版本未另行验证。一次注入探针通过不代表已覆盖全部注入攻击，也不能将这 30 题的结果推广为生产准确率。
