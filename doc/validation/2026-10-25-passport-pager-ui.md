# 蓝牙翻页页布局优化

## 已定位问题

- 放映徽标创建在局部 live 对象中，p_live 未赋值，状态切换时没有正确隐藏徽标。
- 配对、主界面、放映、黑屏的控件平铺在同一父对象，逐个隐藏容易遗漏；模式菜单与提示仍显示底层文字。
- 设备名、说明及菜单文字没有统一尺寸，长文字可以跨区。
- 设备名前缀 memcpy 包含字符串终止符，追加设备名后仍只显示蓝牙图标。
- UI 字体子集没有扫描蓝牙页面/按键模块，且缺少图标字体回退。

## 调整

使用独立内容组统一切换状态，断线时先切回配对状态再更新可见性；菜单隐藏基础视图，提示隐藏说明。长设备名固定宽度单行省略，兼容常用中文；说明允许两行，菜单名称和右侧标签各有独立宽度。修正徽标对象绑定和设备名格式化，增加图标字体回退，重建 UI 字体子集。精简重复提示并提升暗色页面辅助文字对比度。

同时让翻页模式启用方向键按下/松开事件，退出时关闭；补上长按上键进入模式菜单的遗漏分支，保持页面提示与路由一致。

## 验证与范围

真实 LVGL 渲染覆盖配对页、三种翻页模式、中英文长设备名、菜单、临时提示、放映、黑屏、断线恢复，以及 10 次页面重建。所有可见标签检查边界、不重叠，换行文字检查实际高度，图标和中文设备名字形检查通过。人工检查渲染预览。入口 tests/pager_layout_run.py，预览在 output/passport-pager-ui-20261025/。

既有主机/输入协议/音频与 BLE 生命周期回归通过，时钟真实 LVGL 布局回归通过，ESP-IDF 构建通过。仅刷应用区并完成哈希校验；正常启动取得 Wi-Fi IP，实机日志记录进入翻页页时空闲堆约 55.9 KB，观察期间无重启。真实屏幕观感和连接电脑后的 HID 操作仍需用户实际操作确认；原生渲染不等同于实机截图。
