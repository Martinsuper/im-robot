# Passport 0.4.0 配网简化

## 实现

- 开放配网热点保留。ESP32 使用 AP+STA 模式扫描附近 2.4 GHz Wi-Fi，`GET /networks` 返回最多 24 条去重后的网络，带信号强度和开放网络标记。
- 配网页面默认只显示网络选择和密码；隐藏网络、电脑私网 IP 和配对码移至手动配置。
- 保存后重启，以子网 UDP 广播（19389）寻找已开启服务的 Piko；WebSocket 连接仍为 TCP 19388。
- 首次请求携带设备 ID 与每次启动生成的 128 位 nonce。电脑设置显示设备 ID，用户确认绑定该次请求；确认前不下发配对码。配对码最多 5 分钟有效，WebSocket 首次认证同时检查设备 ID、nonce 和配对码。
- 同时有多台电脑时，只在希望连接的电脑确认。已配对设备仍使用持久 token 认证；每次启动重新发现电脑地址。发现回复不广播持久 token。
- 仅配网热点本地地址可读取页面、扫描或提交配置；同时支持 IPv4 和 IPv4-mapped IPv6 地址。
- 保留手动 IP/配对码兼容路径；跨子网或设备隔离网络不支持自动广播发现。
