# Passport 白屏闪烁与启动重启排查

2026-10-25，用户报告一直闪烁白屏，随后授权备份并刷入修复版。

## 原因与修复

实机启动日志：`LVGL pool used 100%, free 44, peak 58344`，随后发生 Store access fault。MEPC `0x42058c22` 使用当时 ELF 解码为 `lv_draw_layer_init`，上层为文字绘制函数。

64 KB 图形固定池不足以支持六页界面。首次改为 96 KB 后，实机显示系统堆仅剩 20492 字节，I2S DMA 与 WebSocket 任务创建失败。改为共享系统堆后，界面初始化时系统堆为 62192 字节，音频 codec 初始化成功，但网络任务仍因内存不足无法启动。

最终配置：LVGL 使用 C library malloc，按需共享 ESP-IDF 堆；Wi-Fi 静态 RX 缓冲 4 个、动态 RX/TX 上限各 8 个、RX BA 窗口 4。默认配置同时补齐 BLE HID 页所需的 NimBLE 配置。启动日志区分共享堆和固定池，并报告系统堆余量。

## 后续：输入页约一秒中断

用户复现后设备日志记录 `send failed errno=12 bytes=807`，随后 `end blocks=11 error=1`；短暂重试未消除 ENOMEM。已新增有限重试及具体发送/录音错误日志，测试覆盖暂时内存不足后恢复和重试耗尽。

随后落实三项内存优化：

- 以内容视图为单位按需构建并销毁 LVGL 控件，停止动画后再删除；共享状态栏和导航常驻。翻页页单独释放控件、保留 BLE 业务状态，日历选中框随月视图创建。
- 设备发现 worker 在输入页暂停 WebSocket、销毁客户端并关闭发现 socket，离开后恢复。客户端生命周期与 JSON/音频发送使用互斥锁协调，停止客户端时不持发送锁，以免阻塞回调。
- 关闭三项可选 Wi-Fi IRAM 加速配置。

三项优化版 ESP-IDF 构建及主机测试均通过，新增 AddressSanitizer 视图生命周期测试完成 700 次切换。仅更新应用区，esptool 写入校验通过。实机启动观察未见崩溃；连续长按录音、各页切换、退出输入页恢复电脑连接仍待用户操作验证。记录不将主机生命周期测试视为实际 LVGL 渲染或网络验收。

## 具体复现：时钟重叠、蓝牙启动失败

- 设备日志明确记录 `NIMBLE_HIDD: HID device profile already initialized`。对照 ESP-IDF 5.5.3 nimble_hidd.c，GATT 初始化失败分支缺少释放，会留下 HID singleton，后续重试直接失败。
- CMake 对构建目录内的 nimble_hidd.c 副本补充 GATT/HID 失败清理和原始返回码日志，不修改 SDK 安装目录；该副本已确认进入编译命令。
- 翻页页也暂停电脑 WebSocket/发现 socket，等待 worker 确认暂停后再启动 BLE，HID 实例数缩为实际使用的一个。
- 时钟农历由 31 px 行高字体改为 17 px 的 UI 字体；移动小时/秒数、UTC、农历与电量位置。打开设置时隐藏 LCD，关闭时恢复。
- 原生 LVGL 真实字体测量曾抓到小时与秒数横向重叠、农历与底行纵向重叠；调整后边界断言和菜单可见性测试通过，并人工检查生成的渲染图。测试入口 tests/clock_layout_run.py。
- ESP-IDF 构建、全套主机回归、输入协议测试通过；应用区刷写校验通过。设备是否能完成首次 BLE 广播及实机时钟显示仍待用户操作复测，未将渲染测试视为硬件验收。
