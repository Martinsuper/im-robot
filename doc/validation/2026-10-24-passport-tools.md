# Passport 0.3.0 语音工具执行验证

日期：2026-10-24。

## 实现范围

转写文字接入桌面同一 Agent，复用人格/记忆、知识检索、提醒/日程/备忘、文件和命令工具。设备使用稳定独立会话，沿用该会话已选择的目录和知识范围。新增 `piko.focus` 原生工具，共用真实桌面计时，开始时不覆盖运行中或暂停中的计时。

业务写操作先进入原有草稿，再展示设备确认卡；短按 OK 确认、长按 OK 拒绝。文件/命令/目录授权、过长预览或设备字体无法显示的内容交给电脑的同一任务窗口。既有命令自动批准偏好仍由原 Agent 控制。旧固件未声明 `voice-confirm-v1` 能力时，全部确认转到电脑。

设备使用新卡片代次与新按下事件门控，防止录音释放、旧卡片事件或重复点击批准操作。服务器确认码一次性且绑定当前语音轮次和原生草稿，不能通过设备批准 desktopOnly 操作。桌面修改任务要求会清除设备旧确认。断线、取消、队列溢出或总超时会停止对应 Agent，不重放写操作；可能已经完成的步骤需在桌面任务记录核对。
