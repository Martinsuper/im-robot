# Piko 灵魂系统实施任务

依据：[设计文档](../design/09-piko-soul-system.md)。本清单拆分实施工作，不表示功能已经实现。所有任务初始状态为待开始；完成时勾选，并记录变更及验证证据。阶段内按依赖推进，不要求按编号机械串行。

## 范围与约定

- P0 交付可编辑人格、开放话题候选审核、任务/问候主动消息与完整关闭能力。
- P1 交付情绪、话题回访、共同历史及忽略退避。
- P2 交付受控人格演化、产出评价、日程建议及称呼演化。
- 任务中的新增模块名称为建议落点；优先复用现有接口。权限门、只读核对和任务恢复语义必须沿用现有实现。
- 默认值、阈值及保留期限以设计文档为准，集中定义，不在 UI、Rust 与 sidecar 中分别维护。
- 不包含云同步、亲密度积分、自动重跑任务或后台模型生成主动消息。

## P0：基础闭环

### S00 · 固化接口与调度契约

- [ ] 完成
- 依赖：无。
- 范围：定义角色快照、设置、话题候选、主动消息、展示回执和来源引用的 Rust/TypeScript DTO；确定命令与事件名称，记录状态迁移表。
- 补齐具体算法：日额度使用时区变化下不倒退的日桶标识，跨重启冷却结合持久化时间与进程内单调时钟保守恢复；明确全局/类别开关、quiet_mode 和静默时段的优先级。澄清会话快照更新入口及 UI 活动状态来源。
- 交付：接口定义及契约说明；设计文档未明确之处以补充决策记录固定，不由不同模块自行猜测。
- 验收：每种主动类别均可映射开关、来源、有效期和去重键；回拨/跨时区/重启不会重置额度；现有普通提醒与灵魂主动消息边界清楚。

### S01 · 建立数据迁移与存储层

- [ ] 完成
- 依赖：S00。
- 范围：在 `src-tauri/src/memory` 下增加角色卡、版本/候选、open_loops、主动账本与额度、情绪快照、共同历史的版本化 schema；后续阶段表可按迁移逐步启用。封装事务与 revision 冲突检查。
- 验收：新建、升级、重复启动幂等；迁移失败保留原数据并禁用对应功能；配置损坏回退默认，账本损坏停止主动投递；写入失败不推进已提交状态。

### S02 · 角色卡默认值、覆盖与编辑命令

- [ ] 完成
- 依赖：S01。
- 范围：提供内置默认卡和多语言文案，持久化用户覆盖，按默认→已确认演化→用户覆盖合成有效角色；实现读取、更新、恢复默认与 revision 校验。P0 演化层为空。
- 验收：首次运行可用；编辑不修改资源文件；并发旧版本编辑不会覆盖新值；恢复默认的版本清理选项含义明确。

### S03 · 统一注入角色快照

- [ ] 完成
- 依赖：S02。
- 范围：通过 `chat::system_prompt` 与 `agent.rs` 统一生成并传递角色快照；检查 `agent/sidecar.mjs` 中新会话及复用会话的配置更新方式，覆盖普通聊天、工具收尾和只读核对路径。每轮固定版本。
- 验收：下一轮生效、轮内不变；用户语气要求可覆盖默认风格；角色内容不能绕过权限与只读限制；复用会话不会继续使用旧角色卡。

### S04 · 开放话题候选提取与审核

- [ ] 完成
- 依赖：S01、S00。
- 范围：扩展 `memory/extraction.rs` 的候选类型、来源引用与去重；仅提取用户直接表达的计划，沿用敏感过滤和审核。支持批准、拒绝、修改与 20 条活动项上限。
- 验收：重复批处理不重复生成，拒绝后不靠同一来源重提；关闭提取后停止新增；批准与写入原子完成；相似来源仅建议合并，不能自动合并。

### S05 · 话题生命周期与时间字段

- [ ] 完成
- 依赖：S04。
- 范围：实现 pending_review/tracking/due/closed/cancelled/expired 迁移；保存原始时间、基准、时区、解析区间与版本。P0 提供审核和手动管理，回访投递在 P1 启用。
- 验收：周末、下个月显示实际日期；模糊时间保持未排期；延期确认产生新 revision；完成/取消/删除可撤销旧消息；普通长期记忆写入仍需单独审核。

### S06 · 主动消息账本与调度内核

- [ ] 完成
- 依赖：S01、S00。
- 范围：新增 `proactive.rs`，实现候选、时间窗、优先级、去重键、每日总额/类别额、全局冷却及 pending/dispatching/shown/终态迁移。投递前事务占用额度，重启不重投状态不明的 dispatching。
- 验收：同刻多个候选只投递一条；休眠恢复只检查仍有效项；过期丢弃；失败和重启不重复提醒；回拨、时区变化不增加额度。P1 退避接口预留但不提前启用。

### S07 · 活动感知与静默门控

- [ ] 完成
- 依赖：S06。
- 范围：接入 quiet_mode、静默时段、锁屏/空闲、用户输入、Agent 执行/等待确认和精灵可见状态。空闲结束稳定 30 秒后检查；开关关闭撤销排队与可见主动消息，保存「不要说话」暂停状态。
- 验收：所有抑制条件不抢占用户；重新开启不补发关闭期间事件；普通权限确认和独立日程提醒维持既有流程。无法可靠读取活动状态时保守延后投递。

### S08 · 气泡、通知与回应上下文

- [ ] 完成
- 依赖：S06、S07。
- 范围：扩展 BubbleWindow 主动消息通道、可见回执、关闭事件、消息 ID 与来源关联。任务待核对通知与气泡共用消息身份；通知权限拒绝不重试。回应进入普通聊天，无回应不生成对话轮次。
- 验收：隐藏气泡不伪造 shown；两种入口指向同一任务/话题；主动模板不注入系统指令；点击或回应不自动授权工具执行；基础关闭/回应事件可供 P1 退避使用。

### S09 · 任务未闭环与问候触发源

- [ ] 完成
- 依赖：S06、S08。
- 范围：接入已提交任务终态及恢复后的 interrupted；failed 提醒查看记录，interrupted 进入只读核对，cancelled 不提醒。记录显式待核对及解决状态，关联重试任务；加入启动/返回问候模板。
- 验收：按设计次日时间窗提醒一次；已解决、过期或被清理任务不重提；日志截断不导致重复提醒；任务消息无敏感提示词/工具输出副本；问候默认关闭。

### S10 · 灵魂设置与开放话题管理 UI

- [ ] 完成
- 依赖：S02、S04、S05、S07、S08。
- 范围：设置页提供选项+自由补充的角色编辑、全局/类别开关和清理入口；记忆中心提供话题审核、时间编辑、手动关闭/取消及未排期提示。未实现的 P1/P2 开关禁用并说明，不能显示为已生效。
- 验收：首次启用清楚说明仅任务未闭环默认开启；保存失败/冲突有反馈；关闭即时生效；中英日现有语言资源均覆盖新增 UI。

### S11 · 清理、保留与本地诊断

- [ ] 完成
- 依赖：S01、S05、S06、S09。
- 范围：落实候选/话题/账本的保留期限、来源删除联动、分项清理及全部清空；保存启用基准，防止扫描旧记录重建。诊断仅记录 ID、模板、状态和跳过原因。若现有导出/导入包含记忆库，则纳入校验，禁止恢复待发队列。
- 验收：清空后重启及重新开启不恢复旧数据；删除来源撤销关联消息；清理墓碑前确认源记录不再可重提；日志无新增正文或凭据副本。

### S12 · P0 集成验收

- [ ] 完成
- 依赖：S03、S09、S10、S11。
- 范围：围绕真实边界补充存储事务、可控时钟调度测试与气泡回执集成验证；建立固定跨模型场景集，覆盖聊天、语气纠正、失败收尾、只读核对及权限请求。
- 验收：设计文档验收矩阵中 P0 相关项全部通过；记录自动检查与人工模型验证结果，不能以单一模型输出逐字一致作为标准。完成后方可开启 P0 默认任务提醒。

## P1：情绪与关系连续性

### S13 · 情绪规则引擎与持久化

- [ ] 完成
- 依赖：S01、S12。
- 范围：实现版本化事件表、可信来源、事件去重、分值阈值/并列选择与时间衰减；恢复时补算离线衰减。低落/担心默认无自动触发；取消及离开不产生负面事件。
- 验收：重复事件不累加，时间回拨不增分；关闭清零，开启不回放；失败累计只影响表达，不改变任务或权限。

### S14 · 情绪表现与设置接入

- [ ] 完成
- 依赖：S13、S03、S10。
- 范围：每轮注入情绪短句，接 SpriteSheet/Cubism 推荐和主动模板；业务状态优先于情绪，缺失动画降级；启用情绪开关。
- 验收：表情与语气一致且不阻塞业务；关闭后恢复平静并从 prompt 移除情绪片段；无责备或要求用户安抚的表达。

### S15 · 开放话题到期回访与回应审核

- [ ] 完成
- 依赖：S05、S08、S12。
- 范围：按固定解析区间生成回访候选，遵守独立开关、7 天窗口和频控；回应生成完成/取消/延期等变更候选，含糊或多话题回应先澄清。
- 验收：没回应不关闭，「还没」保留，「改期」确认后撤销旧版本；完成归档不会自动写长期记忆；回访开关默认关闭。

### S16 · 忽略计数与退避恢复

- [ ] 完成
- 依赖：S08、S12。
- 范围：按实际可见 20 秒、回应与手动关闭区分 ignored/responded/dismissed；实现连续三次忽略后的类别退避与恢复。
- 验收：排队、隐藏、展示失败不计忽略；退避跨重启保留；回应或满足 7 天恢复条件后还原，仍遵守全局硬上限。

### S17 · 共同时间与首批里程碑

- [ ] 完成
- 依赖：S01、S08、S12。
- 范围：持久化启用日期和最小真实事件，唯一键解锁首批里程碑；共同天数按自然日计算；里程碑通过独立主动类别通知，不复制对话。
- 验收：重放不重复解锁；静默时不强行弹出；采纳等事件需要显式证据；清空后建立新基准，不扫描旧历史重建。

### S18 · 模式观察与偶发小话

- [ ] 完成
- 依赖：S08、S12；情绪模板依赖 S14。
- 范围：启用设计中尚未交付的两类主动行为；模式观察仅使用用户已确认的事实和可验证时间字段，小话使用本地模板；模板选取随机性不影响硬频控。
- 验收：默认关闭、离线可用；不推断健康/心理状态、不引用已删来源；遵守类别上限和全局上限，无模型生成调用。

### S19 · P1 集成验收

- [ ] 完成
- 依赖：S14、S15、S16、S17、S18。
- 范围：验证情绪/业务动画冲突、话题复杂回应、退避跨重启及多个类别同时触发。
- 验收：P1 场景通过，P0 静默、权限和去重检查无回归；所有新类别均可单独关闭及清理。

## P2：受控演化与表达

### S20 · 人格演化候选、版本与回退

- [ ] 完成
- 依赖：S02、S03、S19。
- 范围：实现显式证据门槛、字段频控、候选确认、有限热情档位、口头禅候选及版本浏览/回退。演化默认关闭，随机性不修改配置。
- 验收：用户覆盖永远优先；拒绝不重复提议；回退生成新版本并暂停相关候选；最多保留约定版本数，关闭不再生成候选。

### S21 · 本地产出评价与日程过载建议

- [ ] 完成
- 依赖：S08、S19。
- 范围：接入可信预览停留/收藏事件，按产出类型提供可证实的本地表达并走独立评价开关；日程草稿依据实际时间冲突/总时长等确定规则追加温和建议。补充并固定停留阈值与过载阈值后实施。
- 验收：停留不等于满意，模板不虚构质量判断；评价低频且零模型生成；建议不阻塞、不新增拒绝、不自动写观点。日程建议属于当前响应，不绕过权限流程。

### S22 · 称呼演化与里程碑扩展

- [ ] 完成
- 依赖：S17、S19。
- 范围：扩展有真实证据的里程碑；解锁称呼后由用户明确选择或关闭，称呼作为用户设置进入角色快照。
- 验收：解锁不自动改称呼；不引入积分排行、离开惩罚或能力门槛；清理、版本变化和多语言表现一致。

### S23 · P2 集成验收与交付说明

- [ ] 完成
- 依赖：S20、S21、S22。
- 范围：验证演化审核/回退、称呼优先级、评价事实边界及全部清理路径；更新用户说明与实现后的设计差异。
- 验收：全部阶段验收通过；记录已知限制，删除不再适用的预留说明；所有阶段功能可按开关回退，核心 Agent 能独立运行。

## 推荐交付顺序

1. S00 → S01，先固定共享契约与持久化底座。
2. 人格链 S02 → S03；话题链 S04 → S05；主动链 S06 → S07 → S08 → S09 可在底座稳定后分别推进。
3. S10 设置管理与 S11 清理汇合，通过 S12 后交付 P0。
4. 推进 S13–S18，以 S19 为 P1 交付门槛。
5. 推进 S20–S22，以 S23 为 P2 交付门槛。

任务粒度按一个可独立评审的功能单元划分；具体工期需在 S00 完成、接口及复用范围确认后估算，当前不承诺天数。
