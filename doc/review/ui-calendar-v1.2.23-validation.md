## 本轮修复和覆盖

- 窗口正在调整大小时，导航请求仍会更新目标分区，避免点击设置或记录后停留在今天。
- 窄窗口的会话列表和键盘切换保持可用，工作区实际宽度与分隔条数值一致。
- 自动化断言区分对话标题与消息正文，避免同名文本造成错误定位。
- 月历按周一开始排列，跨年翻月正确，返回今天恢复所选日期。
- 选定其他日期后，新建事项使用所选日期；保存后继续添加仍保留该日期。
- 月历数量与所选日程联动，重载后数量和事项保持一致；跨午夜日程的边界由单元测试覆盖。
- 保留并回归了原有的会话转移、草稿、批准操作、引导、记录、备份、通知和设置流程。

浏览器端测试使用隔离的状态和 IPC 替身，不操作用户的真实数据。原生桥接另行运行本机脚本验证。本地未安装新桌面安装包；安装包由 release 工作流在 macOS Apple Silicon、macOS Intel、Windows 和 Linux 构建。

## 发布方式

代码与版本号一起提交到 main，推送 v1.2.23 标签触发 Release Build。工作流首先运行跨平台验证，通过后创建草稿、构建安装包及 SHA-256 校验文件，全部上传成功后发布。
