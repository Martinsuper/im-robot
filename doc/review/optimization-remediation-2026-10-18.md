# 项目优化修复记录（2026-10-18）

| 序号 | 问题 | 修复 |
|---|---|---|
| 1 | 不同设置组相互取消保存 | 偏好和休息提醒各自使用独立、有稳定分组标识的保存队列 |

| 4 | 下载文件名和地址缺少约束 | 校验单文件名、项目正式 Release HTTPS 地址及受信重定向；拒绝路径穿越 |
| 5 | 下载整包占用内存，缺少校验和取消 | 流式写入临时文件，1 GiB 上限，校验 GitHub digest 或发布校验文件；原子提交，失败清理；进度事件及取消命令 |
| 6 | E2E 与聊天入口脱节 | 工作区折叠菜单使用稳定定位器；更新收藏、审批和小窗口流程；默认使用 Playwright 配套 Chromium |
| 7 | 构建完成前公开 Release | 复用质量验证，先创建草稿，所有构建与上传完成后公开；校验标签版本；保留已发布版本保护 |
| 8 | 安装包不匹配架构，遗漏 Linux | 系统与架构联合筛选，支持 macOS、Windows、Linux AppImage；无匹配包引导发布页；验证后授予 AppImage 执行权限 |
| 9 | 明文 API Key 及吞掉读取错误 | 系统凭据存储；成功写入并读回验证后迁移旧文件；错误通过设置和模型请求返回；测试使用模拟凭据 |
| 10 | 导出文本覆盖竞态和非原子写入 | 同目录临时文件；禁止覆盖时使用原子 no-clobber；明确覆盖时原子替换 |
| 11 | 缺少窗口错误边界 | 渲染及懒加载异常显示重试、重新加载和诊断复制入口；处理剪贴板不可用 |
| 12 | SSE 缓冲无上限且反复扫描 | 4 MiB 待处理缓冲上限，记住扫描位置；保留跨 HTTP 块 UTF-8 测试 |
| 13 | 国际化缺 key、文案决定状态 | 补齐三种语言；连接状态使用结构化 kind；更新和设置反馈显式指定 Toast 类型；翻译纳入 CI |
| 14 | 质量门禁和跨平台验证不足 | npm verify 串联现有检查；Lint 零警告；Rust fmt/Clippy 警告清零；CI 增加三平台 Rust/原生 Agent 验证及 macOS 原生桥接测试 |
| 15 | 聊天和设置组件职责过多 | 提取 usePreferenceDrafts、VersionSettings、modelConnectionStatus、useWorkspaceSelection、ChatContextMenu 和通用保存队列 |
