# macOS 原生界面验收（2026-10-22）

## 环境

使用当前工作区构建 `Piko Acceptance.app`，应用标识为
`com.duanluyao.imrobot.acceptance20261022`，拥有独立配置目录和凭据命名空间。
未复制正式应用的对话或密钥。测试配置暂停感知，并使用独立快捷键。

## 已验证

- 应用可以启动，桌面精灵能渲染；菜单可以打开主面板和对话。
- 首次引导三步可完成，跳过模型连接后进入对话。
- 未配置模型时发送合成测试文本，显示配置错误，保留输入草稿。
- 错误提示的“检查设置”可打开设置页；AI 设置显示未选择模型。
- 今天、记录和设置页面可切换；空记录、空对话历史显示正确。
- 设置页可以查询通知权限，显示“尚未授权”；重新检查不会崩溃。
- 主面板返回对话、快捷浮层切换完整窗口，保留当前草稿和错误提示。
- 退出并重新启动后，主面板直接进入今天页面，不再重复首次引导。

## 未覆盖

- 未连接真实模型，未验证真实模型回答或工具任务的完整执行。
- 未授予通知、日历、麦克风或屏幕录制权限；未验证授权后的投递、同步与采集。
- 精灵按钮的辅助功能点击未观察到窗口变化；本轮使用菜单完成入口验收，精灵鼠标点击/拖拽仍需单独验证。
- 本轮是独立标识的验收构建，不替换 `/Applications/Piko.app`，也不代表正式安装升级流程已验收。

验收结束后已通过应用菜单退出隔离实例。正式应用包仍位于
`src-tauri/target/release/bundle/macos/Piko.app`。
