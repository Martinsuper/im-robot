## 隔离环境

验收版使用独立 bundle identifier、配置/数据目录、全局快捷键和空凭据命名空间。凭据服务名改为取 Tauri identifier，正式 identifier 的服务名保持原值。正式 Piko 进程和用户资料未修改。

验收配置暂停主动感知、关闭休息提醒。模型任务只连接本机模拟 HTTP 服务，未向云模型发送测试数据。主题使用 UI 支持的 `blue`。验收结束后应用及模拟服务均已退出。

## 真实 WebView 验收

- 首次启动、跳过引导，主面板、宠物和对话窗口正常显示。

- 恢复显示阻塞遮罩、自动重启。重启后的磁盘及 WebView 只保留快照中的记录；恢复日志清理，回滚快照保留。

## 跨平台修复

- Windows/macOS 专属菜单、日历、通知导入与适配器按平台编译；非支持平台返回明确错误。
- Ubuntu 22.04 保持原验证基线。xcap 使用 0.9.8 本地补丁，把项目未使用的 Linux Wayland 视频录制设为可选，同时条件编译其错误类型；静态截图、Wayland portal 与 X11 截图路径保持不变。补丁附许可证、来源及上游归档 SHA-256，默认 Linux 依赖树不含 PipeWire。
- Linux 补齐空闲检测命令导入，并修复通知设置兜底错误后的不可达代码。
- Windows 快照复制后的文件改用可写句柄执行 sync_all，解决只读句柄刷新导致的拒绝访问，保留落盘保证。
- 时间摘要测试按运行机器时区校验显示，不再写死北京时间。
- 使用进程级数据冻结锁的单元测试互斥执行，避免不同测试数据目录争抢同一全局锁；生产超时限制未放宽。
