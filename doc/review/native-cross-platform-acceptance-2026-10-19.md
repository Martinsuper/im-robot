# 原生与跨平台验收（2026-10-19）

## 独立环境

正式 Piko 保持运行。验收应用使用独立 bundle identifier、配置/数据目录、全局快捷键和空凭据命名空间。为确保不同应用标识不会读取正式 API Key，凭据服务名现在使用 Tauri identifier；正式 identifier 对应服务名保持原值。

构建采用单独的配置覆盖，生成 Piko Acceptance.app。测试开启主动感知暂停、关闭休息提醒，模型仅连接本机模拟 HTTP 服务，没有向云模型发送数据。首次准备配置时应使用合法主题 `sage` 或 `blue`，不能使用 UI 未定义的 `light`。

## 已验证的真实 WebView 流程

- 首次启动、跳过引导，主面板与宠物窗口正常显示。
- 通过 UI 创建测试记录和完整备份，随后新增第二条对照记录。
- 使用原生文件夹选择器预览快照，确认恢复后显示阻塞遮罩并自动重启。
- 重启后，新进程正常显示主面板；磁盘和 WebView 均只保留备份中的第一条记录，第二条对照记录已移除，恢复日志已清理，回滚快照保留。
- 名称修改自动保存，并同步到主面板、对话和宠物窗口；正常退出后仍持久化。
- 未授予屏幕录制权限时，截图入口显示明确错误，窗口仍可使用；没有擅自授予系统权限。
- 对接仅监听 127.0.0.1 的模拟模型，真实 Rust/Node Agent 发起请求；停止按钮令界面恢复可输入且子进程退出。
- 再启动一个模拟请求，正常退出验收应用后，应用与 Agent 子进程均退出。

截图成功及授权后恢复路径需要用户为验收应用授予屏幕录制权限，尚未验证。测试未申请麦克风、输入监控或日历权限。

## 远端验证与修复

草稿 PR：https://github.com/Martinsuper/im-robot/pull/22 。使用临时 Git 索引生成独立分支快照，本地 main 和原暂存区不变；未纳入个人配置与运行时文件。

第一轮前端和安全审计通过；原生矩阵发现：

- Ubuntu 22.04 的 PipeWire 头文件不兼容默认视频绑定。已撤回 0.8.0 降级实验，改用下文记录的 xcap 0.9.8 可选视频补丁，保留 Ubuntu 22.04 验证基线。
- Windows 暴露 macOS 菜单导入、日历授权函数和通知参数的条件编译缺口。按平台限定导入，并让非 macOS 日历授权明确失败；没有开放不支持的平台能力。

第二轮 Linux 与 Windows 失败，原因及修复见下文。第三轮正在运行：https://github.com/Martinsuper/im-robot/actions/runs/39193721817 。

测试证据、配置、模拟服务日志和 CI 状态保存在 `artifacts/native-acceptance/`。文件夹仅含本轮隔离数据的相关证据，不包含正式用户资料；该目录被 Git 忽略。

## 第二轮 CI 后修复

Windows 严格 Clippy 发现 macOS 专属通知分支在其他平台留下无效 return，以及非 macOS 日历适配器位于测试模块之后，已调整条件编译与声明位置。

xcap 0.8.0 降级实验仍无法兼容 Ubuntu 22.04 的 PipeWire 头文件，已撤回。最终保持 xcap 0.9.8，使用保留许可证及来源校验的本地补丁，将 Piko 未使用的 Linux Wayland 视频录制改为可选功能；静态截图、Wayland portal 与 X11 截图路径不变。默认 Linux 依赖树不再包含 PipeWire。macOS 上游截图接口仍有三处弃用警告，后续应随上游替换 API。

## 截图成功路径与权限回收

经用户明确授权，仅给独立验收版临时开启录屏权限。旧构建条目显示开启但预检失败，通过系统设置重新选择当前应用包后，真实 WebView 完成选区、确认并生成 150×100 截图附件；附件随后移除，未发送给模型。应用正常退出，系统设置已确认 Piko Acceptance 录屏开关关闭。正式 Piko 进程及其授权未修改。

最新本地构建、应用包检查、严格 Clippy 均通过；Cargo 安全审计为 0 漏洞。第三轮前端与安全检查已通过，三平台 Rust 检查仍在运行，不能据此宣称跨平台全部通过。

## 后续跨平台回归修复

Linux 实际编译继续发现 `ambient` 的 xprintidle 命令缺少平台导入，以及通知设置兜底错误之后仍返回成功；现已修正。Windows 的快照测试发现，复制后的文件以只读句柄调用 sync_all 会返回拒绝访问；已改为可写句柄刷新，保留持久化保证。时间摘要测试去掉固定东八区字符串，按运行机器本地时区验证显示。

修复后本地 Rust 回归 288 通过、1 忽略，快照专项与完整功能严格 Clippy 通过。最终源代码提交 `ab35ce08e3c082ff94b32e2ec49ee90cf6e92b69`，远端验证：https://github.com/Martinsuper/im-robot/actions/runs/39194695253 。
