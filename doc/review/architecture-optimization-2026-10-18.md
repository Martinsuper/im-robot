# 架构优化实施记录（2026-10-18）

本轮按 WASM、IPC、后台任务、数据归属与备份恢复的顺序完成实施。

## 1. WASM 执行边界

运行器统一配置 1000 万 fuel、2 秒 epoch 截止时间、64 MiB 内存和 512 KiB 栈；输入上限 1 MiB，模块上限 16 MiB。限制实例与表数量，校验规范路径，禁止目录穿越及插件目录外的符号链接。引擎和最多 16 个编译模块复用，源码变化后重新编译。测试覆盖死循环、超时、内存超限和路径约束。

## 2. IPC 与 SDK 边界

Rust AST 生成器从注册命令和 serde 类型生成 TypeScript 合约，目前覆盖 178 个命令、122 个传输类型。`npm run contracts:generate` 更新，`npm run contracts:check` 检查漂移；负向类型样例检查未知命令、缺参及参数类型错误。Agent 事件协议同时生成必要字段定义并在 Node 端校验。

现有 `runCommand<T>` 保留为旧视图模型兼容层，其命令名与参数已受生成合约约束；新代码可直接使用严格的 `invokeCommand`。尚未宣称所有旧视图返回值均完成严格迁移。

Pi SDK 的导入和会话构造集中到 `agent/sdk-adapter.mjs`，运行时打包包含适配器和协议文件。SDK 仍是外部依赖，适配层降低升级影响范围。

## 3. 后台任务生命周期

统一 supervisor 管理具名任务、取消信号、故障和健康状态，退出等待上限 3 秒。调度器、Agent 流与取消监控、活动采集、记忆任务和重型数据操作纳入管理。耗时备份、恢复准备、同步和转录转移到阻塞工作线程。Agent 先协作取消，短暂等待子进程清理后终止；Linux 无停止 API 的键盘监听隔离为可终止子进程。

新增单实例插件，避免两个应用进程同时修改同一份数据。健康接口和设置页面可查看任务与存储锁指标。

## 4. 数据归属与一致性

宠物成长、互动统计、性格状态以 Rust 持久化为准；浏览器数据仅作首次迁移来源或预览环境存储。原生启动先完成读取，写入按键排序并采用版本比较，冲突和失败可见且可重试；删除墓碑防止旧浏览器缓存复活数据。

跨存储一致性门允许普通读写并行参与，在快照时独占冻结。SQLite 使用 backup API，JSON 和 Agent 会话按明确归属清单备份。备份不含凭据、插件程序、缓存、工作区原文件和诊断信息；不应当视为整机或工作区备份。

快照限制 2 GiB、2 万文件，SHA-256 校验内容，拒绝越界路径和非预期符号链接。交互式恢复要求相同应用版本；先预览，再明确确认恢复并重启。启动阶段在窗口和数据库打开前应用恢复；恢复前留存回滚快照，应用中断后下次启动回滚。旧导入与清空操作也有跨存储回滚保护。恢复后撤销旧文件操作授权。

现有业务 JSON 未强行全部迁入 SQLite，也未在缺乏争用证据时引入连接池；先暴露锁等待和持有指标，为后续优化提供依据。

## 依赖与构建

默认保留语音识别和 WASM。可通过 `--no-default-features` 构建精简 Rust 后端；`speech-recognition` 控制 sherpa-onnx/bzip2/tar，`wasm-plugins` 控制 wasmtime/wasmtime-wasi。前端依据能力接口禁用不可用语音入口。

外部依赖仍包括 React/Tauri、Pi SDK、随包 Node、SQLite、可选 WASM/语音引擎及系统原生桥接；云模型与外部日历服务按用户配置启用，不代表所有功能必须联网。

- 前端单元测试：260 项通过。
- Agent：65 项通过，并用随包 Node 22.23.3 和打包 sidecar 再次通过；原生运行时 smoke 通过。
- Rust：288 项通过、1 项忽略；另有 1 项集成测试通过。
- 合约生成器：1 项测试通过；合约漂移、架构、国际化、版本检查和生产构建通过。
- 默认及无默认特性构建均通过严格 Clippy。

- 完整端到端回归：115 项全部通过；截图异常信息前缀问题已修正并验证。

本地验证环境为 macOS ARM64。Windows/Linux 原生运行行为仍需对应 CI/设备验证。测试使用临时数据与模拟服务，未安装或发布应用，未操作真实用户数据；实际迁移在后续启动新版本时执行。
