# 代理检查点与数据导入修复

## 编辑授权与恢复

- 编辑检查点绑定 SDK 规范化后的完整 `edits[]`，使用新的 `edit-v2` 标识，旧检查点不能授权新的批量编辑。
- 通过 SDK 的内存文件操作预计算结果，覆盖多处编辑、BOM、CRLF 和字面量替换；预计算不会写入工作目录。
- 已落盘的编辑可在中断后验收，无需重复写入；更换编辑内容必须重新授权。
- SDK 仍延迟加载，保留初始化超时和取消机制。

## 导入行为

- 导入设置只恢复静默模式、宠物名称、主题和感知暂停偏好。
- 本机模型配置和凭据保持不变。旧格式中的模型字段仍可解析，但不会用于覆盖本机配置，避免已有密钥被发送到备份指定的服务器。
- 对话不再限制为 50 条，按现有策略保留最近 200 个会话；同一会话可包含超过 50 轮对话。
- 合并按记录 ID 去重，已有内容优先。返回值 `chatsImported` 为实际保留的新增记录数，`chatsSkipped` 为重复或因会话保留策略跳过的输入记录数。

## 验证

- 代理测试：71 项通过；随包 Node 运行相同测试：71 项通过。
- Rust 库测试：344 项通过，4 项忽略。
- 通过版本、架构、国际化、IPC 契约检查及全功能、全 target 的 Clippy 检查。
- 新回归场景包括：更换编辑内容不能复用授权，编辑执行前后中断恢复，BOM/CRLF，真实 sidecar 的旧版与批量编辑参数，导入模型配置隔离，超过 50 轮的恢复，重复记录和会话保留计数。
