# Passport Pager · Bluetooth page turner for AI Passport

[中文](README.md) · **English**

Turns the [FoloToy AI Passport](https://github.com/FoloToy/ai-passport) (an ESP32-C3 badge) into a Bluetooth page turner: advance Keynote / PowerPoint slides on a Mac, or turn pages on an e-reader such as BOOX. No driver to install. Pair once and it reconnects automatically after every power-on.

![The UI in PassportSim: waiting to pair, paging, the three modes, and the forget-pairing prompt](docs/images/screens.png)

<sub>Screenshots taken in the [PassportSim](https://github.com/BlackHole1/passportsim) emulator. The on-device UI is in Chinese.</sub>

## Features

- **Three paging modes**, cycled with the function key and remembered across power cycles:

  | Mode | Up key | Down key | Good for |
  | --- | --- | --- | --- |
  | Arrow keys | ← | → | Keynote, PowerPoint, most readers |
  | Page keys | Page Up | Page Down | PowerPoint, web pages, some readers |
  | Volume keys | Volume + | Volume − | BOOX and other Android readers (enable "volume keys turn pages" in the reader) |

- **Standard Bluetooth keyboard** (BLE HID): pairs directly with macOS, Windows and Android, no extra software.
- **Shows who it is connected to**: after pairing the screen reads "已连接到 NoteX6" (connected to NoteX6) with the host's device name.
- **Status bar** in the top-right corner: Bluetooth state (grey = not connected, blue = connecting, green = connected) and battery percentage, red below 15%.
- **Battery level reported to the host** through the BLE Battery Service, so it shows up in the macOS Bluetooth menu.
- **Remembers up to 4 devices** and reconnects to the last one on power-on.
- Chinese UI. The font is generated from Source Han Sans with only the characters the UI uses, plus the 3,755 most common Chinese characters (GB2312 level 1) so Chinese device names render.

## Buttons

| Button | Action |
| --- | --- |
| Up | Previous page |
| Down | Next page |
| Function, single click | Cycle the paging mode |
| Function, double click | Ask "forget pairing?": press Function within 5 s to clear all pairings, Up / Down to cancel |

## Usage

1. Flash the firmware (next section).
2. In the Bluetooth settings of your computer or reader, pick **Passport Pager**. No PIN needed.
3. When the screen shows "已连接到 …" and the Bluetooth icon turns green, start paging.

**BOOX**: enable volume-key page turning in NeoReader's settings, then switch the pager to Volume keys mode. You can also try Arrow keys mode first.

**Switching hosts**: the pager stays connected to one host at a time. Disconnect it on the current host; it starts advertising again and the other host can connect.

## Flashing

> ⚠️ Back up the whole flash first. The AI Passport ships with the XiaoZhi voice assistant, and option 1 below overwrites it.

**Option 1: full-flash image (simplest)**

Download `passport-pager-merged.bin` from [Releases](https://github.com/Gchen961/passport-pager/releases/latest), then:

```sh
# Back up the whole 8 MB flash first
esptool.py --chip esp32c3 read-flash 0 0x800000 passport-backup.bin
# Write the full image
esptool.py --chip esp32c3 write-flash 0x0 passport-pager-merged.bin
```

FoloToy's official web flasher can write the merged image too.

**Option 2: keep XiaoZhi, write only OTA_1**

This project uses the same partition table as the factory XiaoZhi firmware (ota_0 and ota_1, 3 MB each). Write only the app into OTA_1 (`0x310000`) and point the second OTA record (`0xe000`) at OTA_1; XiaoZhi stays in OTA_0. The pager's first boot is a trial boot, and the bootloader rolls back to XiaoZhi if it fails. `passport-pager-app.bin` in Releases is the app to write. This requires editing the OTA record by hand, and writing the wrong sector leaves the board unbootable; a step-by-step guide with verification is still being written, and contributions are welcome.

## Building from source

Requires **ESP-IDF 5.5.3** (FoloToy's official BSP pins `>=5.5.3,<5.6.0`).

```sh
git clone https://github.com/Gchen961/passport-pager.git
cd passport-pager
. ~/esp/esp-idf-v5.5.3/export.sh
idf.py build                          # app: build/passport_pager.bin (about 1.6 MB)
idf.py merge-bin -o merged.bin        # full image: build/merged.bin
```

All configuration lives in `sdkconfig.defaults`. `sdkconfig` is generated by the build and is not tracked; put configuration changes in `sdkconfig.defaults`.

## Trying it without a board

[PassportSim](https://github.com/BlackHole1/passportsim) emulates the AI Passport's screen, buttons and Bluetooth:

```sh
passportsim start "$(pwd)/build"          # boot it; the path must be absolute
passportsim screenshot --save-as home     # take a screenshot
passportsim input down click              # press Down
passportsim ble_connect --service 1812    # connect the emulated BLE host to the pager
passportsim ble_gatt notifications        # key reports received, e.g. 00 00 4f = →
```

Add `--instance p1` when several instances are running. PassportSim emulates Bluetooth only for firmware built with IDF 5.5.3. Its scripted host does not pair, so in the emulator the status stays "正在连接…" (connecting) and no device name appears.

Espressif's [esp-emulator](https://github.com/espressif/esp-emulator) can also check boot and BLE advertising.

## Changing the UI text

The Chinese font is generated from Source Han Sans with only the characters the UI needs. After changing Chinese strings in `main/`, regenerate it:

```sh
npm install lv_font_conv@1.5.2           # LVGL's official font converter
LV_FONT_CONV=./node_modules/.bin/lv_font_conv tools/gen_fonts.sh
```

The boot log prints `Glyph check: 0 of N glyphs missing`; anything other than 0 means a character is missing from the font.

## Project layout

```
main/
  main.c           UI, buttons, status bar, battery
  pager_ble.c/h    BLE HID: advertising, pairing, key reports, peer name, battery service
  pager_keys.c/h   key codes for each paging mode
components/bsp/    FoloToy's official board support package (display, buttons, fuel gauge, ...)
assets/fonts/      generated Chinese fonts and their character lists
tools/gen_fonts.sh font generator
partitions.csv     partition table matching the factory XiaoZhi firmware
```

## Known limitations

- One host connection at a time; disconnect on the current host before switching.
- Battery level refreshes every 30 seconds.
- Volume keys mode really changes the volume on a Mac; use Arrow keys mode there.

- [ ] Hold the function key to switch between two paired hosts

- [ ] Media mode (previous / next track, play / pause)
- [ ] Short-video mode (emulated swipe-up gesture)
- [ ] Turn the screen off after a period of inactivity

1. Build with IDF 5.5.3;
2. Verify the change in PassportSim or on a real board;
