# Piko Passport 固件版本归档

本目录按版本保存固件镜像（各版本是否实机验证见对应说明），用于回滚。镜像与说明文档一并入库（单个镜像最大 3.4 MB，远低于仓库限制；`backup/` 中的原始读回副本仍仅保留在本地）。更早版本的功能沿革见 [../README.md](../README.md) 的版本记录。

## 回滚方法

设备：FoloToy AI Passport，ESP32-C3，8 MB Flash。分区布局：bootloader `0x0`、分区表 `0x8000`、应用 `0x10000`（应用区上限 `0x350000`）。设备身份区 `0x356000..0x35a000` 禁止写入。

刷写前必须确认串口，**禁止整片擦除（erase_flash）、禁止写入合并镜像**。使用 ESP-IDF 环境中的 esptool：

```sh
# 例：回滚到 0.7.1（该版本归档为设备实测读回镜像，见下文说明）
python -m esptool --chip esp32c3 -p <串口> -b 460800 write_flash \
  0x8000 0.7.1/partition-table-0.7.1.bin \
  0x10000 0.7.1/app-0.7.1.bin

# 例：刷入 0.8.0（三段完整镜像）
python -m esptool --chip esp32c3 -p <串口> -b 460800 write_flash \
  0x0 0.8.0/bootloader-0.8.0.bin \
  0x8000 0.8.0/partition-table-0.8.0.bin \
  0x10000 0.8.0/Piko-Passport-0.8.0.bin
```

NVS（Wi-Fi、配对凭据）不在上述写入范围内，回滚不会丢失配网与配对数据。回滚后设备首次启动会自动重连电脑。

## 0.7.1（2026-10-24，已被 0.8.0 取代）

功能完整版：六页 UI——**陪伴、专注、消息、语音、连接、输入**。

- 陪伴页：18 帧 OpenPets 宠物动画（待机/专注/开心状态），短按打招呼触发电脑互动
- 专注页：25 分钟专注计时（开始/暂停/继续），长按打开结束确认
- 消息页：显示连接与操作回执，可翻页
- 语音页：按住 OK 说话，SenseVoice 本地识别，设备扬声器播报回复（最多 40 秒）；支持 MiMo 流式播放与持续按住录音（`voice-long-upload-v1`）
- 连接页：自动发现/发起连接、断开/恢复、解除配对（0.6.0 引入）
- 输入页：随身语音输入，文字经电脑输入法写入光标处（0.7.0 引入）；0.7.1 修复输入模式上键事件过滤问题并完成实机验证

**本目录镜像的来源说明**：0.7.1 源码未入库（`firmware/` 首次提交即为 0.8.0），此归档是刷入 0.8.0 前从设备应用分区完整读回的实测镜像（3,407,872 字节 = 整个应用区，含填充），回滚时按上表偏移整块写回即可。bootloader 未单独读取——0.7.1 与 0.8.0 使用同一版 ESP-IDF 5.5.3 且 bootloader 配置未变，如需恢复 bootloader 可借用 0.8.0 的 `bootloader-0.8.0.bin`。

## 归档规则（新增版本时）

1. 构建并刷写成功、实机确认后，从 `build/` 复制 `bootloader/bootloader.bin`、`partition_table/partition-table.bin`、`Piko-Passport.bin` 三个文件到 `releases/<版本号>/`，文件名带版本号，并随代码一并提交
2. 在本 README 增加版本小节：功能变化概要、镜像大小、写入偏移、SHA-256（`shasum -a 256`）
3. 若新版回滚需覆盖旧版（例如不再兼容的分区变更），在对应小节显式标注
