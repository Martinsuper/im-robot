# Live2D Model Assets

This directory is reserved for downloaded Live2D runtime model assets.

Recommended layout:

```text
public/live2d/models/
  epsilon/
    Epsilon.model3.json
    Epsilon.moc3
    textures/
    motions/
    expressions/
  miara/
    miara.model3.json
    miara.moc3
    textures/
    motions/
```

Download official sample models from:

```text
https://www.live2d.com/en/learn/sample/
```

Before bundling a model in the app, confirm that its license permits the intended use and redistribution.
