# 桌宠与对话窗口交互

## 入口

- 单击桌宠打开或聚焦现有对话，不切换隐藏；键盘 Enter / Space 同样可用。
- 拖动沿用距离阈值，移动后不会触发点击。
- 主动打开对话时焦点交给对话窗口，不再延迟抢回桌宠。
- 打开主面板不会自动隐藏对话，二者可以并排使用。

## 两种对话视图

- 默认是无系统标题栏的快捷浮层，显示在桌宠附近。
- 顶栏「在完整窗口继续」在原窗口上开启系统标题栏并放大。
- 「返回快捷浮层」退出全屏／最大化，并恢复切换前的浮层尺寸。
- 切换不重新挂载对话，不创建会话，不取消任务，不清空草稿或审批。
- 主面板继续承载记录和设置；当前尚未合并为带统一导航的完整工作台。
- Esc 优先关闭局部菜单，其次隐藏对话；不会取消后台任务。
- 系统关闭按钮隐藏对话，不销毁窗口；最小化后再次打开会恢复显示。

## 低打扰

- 空闲小动作不再播放声音。
- 注意力提示调整为至少间隔 3–5 分钟，每次约 1.6 秒；安静模式不提示。
- 不新增点击外部自动隐藏，避免打断输入和待确认操作。

## 桌面验收

1. 连续点击桌宠，已有对话保持可见且输入框可输入。
2. 输入草稿、展开、返回，草稿保持不变。
3. 任务执行和等待审批期间切换视图，状态及审批保持不变。
4. 完整窗口可最小化、最大化／macOS 全屏；返回浮层恢复尺寸。
5. 打开设置，对话不消失；关闭对话后桌宠能重新唤起。
6. 在小屏、多显示器和不同缩放比例下检查展开尺寸与位置。

原生窗口交互需要打包应用实测；浏览器测试不能验证系统标题栏和焦点行为。
