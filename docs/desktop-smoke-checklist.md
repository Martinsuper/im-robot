# Piko 桌面冒烟清单

## 通用

- 安装、启动、退出、重启。
- 精灵透明置顶，可拖动，重启后位置恢复。
- 单击精灵打开气泡；托盘可隐藏和恢复精灵。
- 气泡可调整尺寸，重启后尺寸恢复。
- 文本聊天可流式回复、停止生成、复制结果。
- 拖入或选择文本附件后可预览、移除，并执行总结、翻译、解释。
- 创建提醒后可收到一次系统通知，重启后未到期提醒仍存在。
- 截图提问可框选、预览、移除，确认后才发送给模型。
- 面板可刷新最近对话，后续提问携带最近六轮上下文。
- 检查更新可查询 GitHub Releases，并在有发布页时打开下载地址。

## macOS

- 首次截图时系统提示屏幕录制权限；拒绝后界面给出明确错误。
- `Command+Shift+Space` 打开气泡。
- Keychain 保存 API Key，配置文件中不出现明文密钥。

## Windows

- `Ctrl+Shift+Space` 打开气泡。
- 系统缩放为 125% 和 150% 时，截图框选区域与预览一致。
- 托盘隐藏、恢复和开机启动工作正常。

## Linux

- Ubuntu LTS + GNOME X11 下完成全部通用项。
- Wayland 下验证截图能力；不支持时展示明确提示。
- `Ctrl+Shift+Space` 打开气泡。
