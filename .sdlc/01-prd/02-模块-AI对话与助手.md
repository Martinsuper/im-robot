# 模块 02 · AI 对话与助手

> 关联：[00-产品总览与设计原则](./00-产品总览与设计原则.md) · [01-模块-桌面精灵与陪伴](./01-模块-桌面精灵与陪伴.md) · [04-模块-记录与记忆](./04-模块-记录与记忆.md)
> 代码位置（现状）：`src/features/chat/*`、`src-tauri/src/chat.rs`

---

## 1. 模块目标

让「问一句」这件事足够快、足够稳、足够懂上下文：

- **快**：打开 → 输入 → 得到首个字，全程 < 2 次操作。
- **稳**：流式不中断、失败有兜底、可停止、可重试。
- **懂**：自动带上最近上下文、附件、截图、记忆。

---

## 2. 范围

### 2.1 包含

- 对话窗口的布局与状态。
- 发送 / 流式接收 / 停止 / 重试 / 复制 / 朗读 / 保存。
- 附件（文本文件）、截图提问、语音输入。
- 对话动作确认（工具调用）。
- 会话上下文与历史。
- 模型服务配置（简化版）。

### 2.2 不包含

- 用户笔记与 AI 长期记忆的存储（模块 04）。
- 精灵动画（模块 01）。

## 3. 对话窗口

### 3.1 定位

**唯一对话入口**。精灵点击、快捷键、托盘、面板「开始对话」都打开它。
面板内不再有独立聊天页（历史在「记录」中查看）。

### 3.2 布局（三层）

```text
┌───────────────────────────────────────────────┐
│ ① 顶栏：头像 · Piko · 状态          ·  展开  ✕  │  40px
├───────────────────────────────────────────────┤
│ ② 对话区（可滚动）                             │
│    - 历史折叠条（若有）                        │
│    - 用户消息（右）                            │
│    - Piko 回复（左，Markdown）                 │
│    - 回复工具条（复制/朗读/保存/更多）         │
│    - 动作确认卡片（如需要）                    │
│    - 空状态（问候 + 3 个建议）                 │
├───────────────────────────────────────────────┤
│ ③ 输入区                                       │
│    - 已选上下文 chips（附件 / 截图）           │
│    - 工具栏（附件 / 截图 / 语音）              │
│    - 输入框 + 发送 / 停止                      │
└───────────────────────────────────────────────┘
```

### 3.3 窗口规格

| 属性 | 值 |
| --- | --- |
| 默认尺寸 | 420 × 560 |
| 可缩放 | 是（min 360×420，max 720×900） |
| 记忆尺寸 | 是，重启恢复 |
| 置顶 | 是，但失去焦点 3s 后可自动降低层级（可配置） |
| 关闭 | 隐藏而非销毁；再次打开保留当前会话 |
| 拖动 | 顶栏可拖动 |
| 快捷键 | `Esc` 收起；`Cmd/Ctrl + Enter` 发送 |

### 3.4 顶栏

- 左：Piko 头像（随状态变化）+ 名称。
- 中：状态点 + 文本（就绪 / 思考中 / 正在输入）。
- 右：`展开`（切换大尺寸）、`✕`（收起）。

**移除**：现状顶栏中的自定义拖动逻辑与「关闭按钮」混用，改为统一的窗口控制区。

## 4. 对话状态机

对话区在同一时刻只处于一种主状态：

| 状态 | 展示 |
| --- | --- |
| `empty` | 空状态：问候 + 建议问题 |
| `composing` | 用户正在输入（无特殊展示） |
| `thinking` | 骨架屏 + 「Piko 正在思考」 |
| `streaming` | 流式文字 + 光标 |
| `done` | 完整回复 + 工具条 |
| `awaiting_confirm` | 动作确认卡片 |
| `failed` | 错误卡片 + 重试按钮 |
| `cancelled` | 已停止提示 + 重新生成 |

规则：

- `thinking` 超过 8s 显示「还在思考，稍等一下…」。
- `failed` 必须给出可操作按钮（重试 / 检查设置）。
- 停止后保留已生成内容，不整段清空。

---

## 5. 发送流程

```text
用户输入
  → 组装上下文（最近 N 轮 + 附件 + 截图 + 相关记忆）
  → 乐观插入用户消息
  → 进入 thinking
  → 流式接收（SSE）
      ├─ 文本 delta → streaming 追加
      ├─ action-proposed → awaiting_confirm
      └─ error → failed
  → completed → done（触发精灵 success、记录写入）
```

上下文规则：

- 默认携带最近 10 轮对话。
- 附件内容截断到上限（默认 20000 字符）并显式提示「已截断」。
- 截图作为图像消息（若模型支持），否则提示不支持。
- 相关记忆最多注入 5 条，标注来源。

## 6. 输入区

### 6.1 工具栏

| 按钮 | 行为 |
| --- | --- |
| 附件 📎 | 打开文件选择；仅支持白名单文本类型 |
| 截图 ▢ | 进入框选截图 |
| 语音 🎙 | 按住 / 点击开始录音，松开转写 |

- 语音输入：录音中显示波形与计时；转写成功后填入输入框，不自动发送。
- 附件与截图以 chip 展示，可单独移除。
- 输入框 placeholder 随上下文变化（默认「问点什么，或让我记一件事」）。

### 6.2 发送与停止

- 发送按钮在无内容时禁用。
- `thinking` / `streaming` 时发送按钮变为停止按钮。
- 停止后展示「已停止 · 重新生成」。

### 6.3 附件处理

- 支持类型：`txt md json csv log yaml yml xml html` + 代码文件（`.ts .tsx .js .jsx .py .rs .go .java .c .cpp .css .sh`）。
- 单文件 ≤ 1MB，单次仅 1 个。
- 拖入不支持类型 → 提示「这个文件类型我暂时看不了（支持文本类）」。
- 选择附件后展示 chip + 3 个快捷动作：**总结 / 翻译 / 解释**。

## 7. 回复呈现

### 7.1 Markdown 支持

- GFM 表格、列表、引用。
- 代码块：语言标签 + 复制按钮。
- 数学公式：KaTeX。
- 链接：默认在系统浏览器打开，带确认。
- 图片：自适应宽度，最大高度限制。

### 7.2 回复工具条

| 操作 | 说明 |
| --- | --- |
| 复制 | 复制纯文本，成功后 1.5s 反馈 |
| 朗读 | 本地 TTS 播放 / 停止 |
| 保存 | 保存为文件（白名单类型，覆盖前确认） |
| 更多 | 重新生成 / 打开设置 / 加入记录 |

### 7.3 长回复

- 超过 1200 字时默认折叠到 600 字，底部「展开全部」。
- 代码块默认完整展示。

## 8. 动作确认（工具调用）

当模型决定调用工具（如创建提醒、写文件）时，不直接执行，而是进入确认流程。

### 8.1 确认卡片

```text
┌─────────────────────────────────────┐
│  Piko 想这样做                       │
│  ─────────────────────────────────  │
│  📅 创建提醒                          │
│  「明天 10:00 项目评审」              │
│                                      │
│  [ 取消 ]            [ 确认执行 ]     │
└─────────────────────────────────────┘
```

- 卡片展示：动作类型、可读摘要、关键参数。
- 危险动作（写文件 / 覆盖）用警示色 + 二次确认。
- 支持「本次会话都允许该动作」（仅限只读类）。

### 8.2 执行后

- 执行结果回填到对话流（简短）。
- 若模型需要基于结果继续，则自动继续生成收尾回复。
- 执行失败：展示原因 + 重试。

### 8.3 边界

- 只读工具：可自动执行并回传（如查询日程）。
- 写入工具：必须确认。
- 未在注册表中的工具：拒绝并提示。

---

## 9. 语音

- **输入**：录音 → 转写（SenseVoice 优先，回落 Whisper）。
- **输出**：本地系统 TTS 朗读回复。
- 首次使用语音时提示下载模型（若未下载）。
- 朗读过程中精灵进入 `speaking` 状态。

## 10. 模型服务配置（简化）

### 10.1 默认只暴露两项

```text
服务：  [ OpenAI Compatible ▼ ]
API Key：[ •••••••••••••••• ]
[ 测试连接 ]
```

- 选择服务后自动填好 Base URL 与默认模型。
- 支持的预设服务：OpenAI Compatible、Anthropic、Google Gemini、DeepSeek、通义千问、本地（Ollama / LM Studio）。
- 「本地」服务无需 API Key，自动探测本机常见端口。

### 10.2 高级设置（折叠）

```text
▸ 高级设置
   Base URL   [ .............. ]
   Model      [ .............. ]
   Temperature[ 0.7 ]
   超时（秒） [ 120 ]
   语音模型   [ SenseVoice ▼ ] [下载]
```

- 高级设置默认折叠，展开状态本地记忆。
- 每个字段有简短说明与推荐值。
- 不再在面板主设置区展示 Base URL / Temperature / Timeout。

### 10.3 连接测试

- 一键测试，返回三态：成功（含模型名）/ 失败（含可读原因）/ 未配置。
- 失败原因翻译成人话（如「无法连接本机 11434 端口，请确认 Ollama 已启动」）。

### 10.4 未配置时的降级

- 未配置模型也能打开对话，展示引导卡「先连接一个 AI 才能聊天」+「去设置」。
- 引导中已完成配置的用户不重复提示。

## 11. 空状态与建议

首次打开对话窗口且无历史时展示：

```text
   （Piko 形象）
   你好，我是 Piko 👋
   可以问我问题，也可以让我帮你记点东西。

   [ 帮我总结这段文字 ]  [ 提醒我 10 分钟后喝水 ]  [ 今天有什么安排 ]
```

- 建议问题点击后填入输入框并聚焦，不自动发送。
- 根据时段与上下文替换建议（如上午推荐「梳理今天安排」）。

## 12. 错误处理

| 场景 | 文案 | 操作 |
| --- | --- | --- |
| 网络错误 | 「网络好像不太稳定」 | 重试 |
| 超时 | 「等太久啦，要不要重试？」 | 重试 / 增加超时 |
| 认证失败 | 「API Key 好像不对」 | 去设置 |
| 模型不存在 | 「没找到这个模型」 | 去设置 |
| 附件过大 | 「文件太大了（上限 1MB）」 | 重新选择 |
| 不支持的模型能力 | 「这个模型看不了图片」 | 换模型 / 去设置 |
| 未知错误 | 「出了点小状况」+ 错误详情（可展开） | 重试 |

禁止直接展示 Rust / HTTP 原始错误。

## 13. 数据模型

```ts
interface ChatMessage {
  id: string;
  role: "user" | "assistant" | "system";
  content: string;
  createdAt: number;
  attachments?: AttachmentRef[];
  screenshotId?: string;
  status: "pending" | "streaming" | "done" | "failed" | "cancelled";
}

interface ChatSession {
  id: string;
  title: string;            // 自动摘要生成
  messages: ChatMessage[];
  createdAt: number;
  updatedAt: number;
}

interface ActionDraft {
  id: string;
  toolName: string;
  summary: string;
  arguments: Record<string, unknown>;
  risk: "read" | "write";
}
```

存储：

- 会话与消息存 Rust 侧（替换现状 `list_chat_history` 的扁平结构）。
- 历史列表展示 `ChatSession`，而非单条问答对。
- 保留最近 200 个会话，超出提示清理。

## 14. 验收标准

- [ ] 打开到可输入 < 500ms；首字返回 < 2s（本地模型除外）。
- [ ] 流式、停止、重试、复制、朗读、保存全部可用。
- [ ] 附件白名单生效，非法类型有友好提示。
- [ ] 截图框选 → 预览 → 发送闭环可用。
- [ ] 语音输入转写正确填入，不自动发送。
- [ ] 写工具必须经过确认卡片，只读工具可自动执行。
- [ ] 未配置模型有引导，配置失败有人话原因。
- [ ] 空状态、错误状态、加载状态文案齐全且无技术术语。
- [ ] 对话窗口尺寸记忆、置顶行为、快捷键符合规范。
