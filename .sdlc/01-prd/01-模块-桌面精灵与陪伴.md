# 模块 01 · 桌面精灵与陪伴

> 关联：[00-产品总览与设计原则](./00-产品总览与设计原则.md) · [07-UI设计规范与交互框架](./07-UI设计规范与交互框架.md)
> 代码位置（现状）：`src/features/pet/*`、`src/features/app/LiveCharacterPet.tsx`

---

## 1. 模块目标

让 Piko 在桌面上「存在得刚刚好」：

- **有存在感**：用户抬头能看到一个有生命的伙伴，而不是一张贴图。
- **有回应**：任何一次交互都在 150ms 内给出视觉反馈。
- **不打扰**：默认不抢焦点、不弹窗打扰、不发声干扰。

本模块只负责「陪伴」，不负责对话内容的生成（见模块 02）。

---

## 2. 范围

### 2.1 包含

- 精灵窗口的显示 / 隐藏 / 置顶 / 拖动 / 位置记忆。
- 鼠标交互语义：悬停、单击、双击、长按、右键、抚摸、拖拽、拖入文件。
- 精灵状态机与表现（待机 / 思考 / 说话 / 休息 / 成功 / 出错 / 被拖动）。
- 亲密度与成长阶段。
- 外观风格选择。
- 安静模式（打扰档位）。
- 主动行为（小动作、注意力脉冲、问候）。

### 2.2 不包含

- 对话内容的生成与展示（模块 02）。
- 提醒、日程、专注的业务逻辑（模块 03）。
- 系统托盘与全局快捷键（模块 06）。

---

## 3. 窗口行为

| 属性 | 规则 |
| --- | --- |
| 尺寸 | 固定 200 × 240（逻辑像素），不可缩放 |
| 背景 | 完全透明，无边框 |
| 置顶 | 静默置顶，位于普通窗口之上、全屏应用之下 |
| 任务栏 | 不显示（`skipTaskbar`） |
| 焦点 | 不主动抢焦点；点击时也不进入系统任务切换 |
| 位置 | 用户拖动后记忆，重启恢复；恢复时若越界则回落到右下角安全区 |
| 多屏 | 记忆屏幕标识；换屏后若坐标不可见，回落到主屏右下角 |
| 全屏应用 | 检测到全屏 / 演示模式时自动隐藏，退出后恢复 |

### 3.1 位置恢复规则

```text
保存：{ screenId, x, y }（相对该屏幕工作区）
恢复：
  if 屏幕不存在 → 主屏右下角
  if x/y 超出工作区 → 钳制到工作区边缘内 8px
```

### 3.2 显示与隐藏

- 托盘「显示 / 隐藏 Piko」。
- 全局快捷键默认 `Command/Ctrl + Shift + Space`：切换对话窗口（不是切换精灵）。
- 精灵自身菜单中的「隐藏」：隐藏只是不可见，仍在托盘运行。
- 首次启动默认显示，并播放一次「入场」动画。

## 4. 交互语义

所有鼠标原始输入先归一化为**语义事件**，再由统一的 `InteractionManager` 决定精灵反应。

| 用户行为 | 判定规则 | 语义事件 | 精灵反应 | 声音 |
| --- | --- | --- | --- | --- |
| 悬停 | 指针进入精灵区域 | `hover` | 视线跟随指针 | 无 |
| 移出 | 指针离开 | `hover_leave` | 视线回正 | 无 |
| 单击 | 位移 < 4px，< 400ms | `click` | 「打招呼」动画 | 轻点击音（安静模式下静音） |
| 双击 | 两次单击 < 320ms | `double_click` | 休息 / 唤醒 | 唤醒音 |
| 长按 | 按住 ≥ 600ms 且位移 < 4px | `long_press` | 打开快捷菜单 | 无 |
| 右键 | 鼠标右键 | `context_menu` | 打开快捷菜单 | 无 |
| 抚摸 | 路径距离 > 24px 且终点位移 < 16px | `pet_stroke` | 「开心」动画 + 亲密度 +2 | 开心音 |
| 拖拽 | 终点位移 ≥ 16px | `drag_end` | 「被放下」动画，保存位置 | 无 |
| 拖入文件 | 拖拽释放时带文件 | `drop_file` | 「好奇」动画 → 打开对话附件 | 好奇音 |
| 拖入文本/链接 | 释放时带 `text/uri-list` | `drop_text` | 「倾听」动画 → 打开对话并填入 | 无 |

### 4.1 判定阈值（唯一来源）

| 阈值 | 值 | 说明 |
| --- | --- | --- |
| 点击最大位移 | 4 px | 超过则不算点击 |
| 点击最大时长 | 400 ms | 超过则不算点击 |
| 双击间隔 | 320 ms | 两次点击间隔 |
| 长按最短时长 | 600 ms | 且位移 < 4px |
| 拖动最小位移 | 16 px | 终点位移 |
| 抚摸最小路径 | 24 px | 累计路径距离 |
| 抚摸最大终点位移 | 16 px | 终点位移小于此值才算抚摸 |

> 阈值集中在 `interactionRules.ts`，禁止散落在组件里。

### 4.2 交互优先级

```text
长按 > 拖动 > 抚摸 > 双击 > 单击
```

同一手势只能触发一个语义事件；拖动过程中不触发悬停 / 抚摸。

## 5. 精灵状态机

目标态把现有 `petState.ts` 的模式收敛为 **7 个可见状态**，其余内部状态不对外暴露。

| 状态 | 触发 | 表现 | 自动恢复 |
| --- | --- | --- | --- |
| `idle` | 默认 | 呼吸循环、偶尔小动作 | — |
| `listening` | 悬停 / 聚焦输入 | 抬头、视线跟随 | 指针离开后 800ms |
| `thinking` | 对话进行中 | 思考气泡 / 轻微晃动 | 对话结束 |
| `speaking` | 流式回复中 | 嘴部或身体节奏动 | 回复结束 |
| `resting` | 双击 / 长时间无交互 | 闭眼、慢呼吸 | 双击唤醒 |
| `success` | 提醒完成 / 专注结束 | 跳跃 + 庆祝 | 2.4s 后回 idle |
| `error` | 出错了 | 轻微摇头 / 担心表情 | 2.4s 后回 idle |

### 5.1 状态转移图

```text
        ┌──────────────────────────────────────┐
        │                                      │
        ▼                                      │
     [idle] ──hover──▶ [listening] ──leave────┘
        │  ▲
        │  │
   chat │  │ complete
        ▼  │
    [thinking] ──delta──▶ [speaking] ──▶ [idle]
        │
   double click / idle timeout
        ▼
     [resting] ──double click──▶ [idle]

     reminder/focus done ──▶ [success] ──▶ [idle]
     error ──▶ [error] ──▶ [idle]
```

### 5.2 与现状的差异

- 删除 `fidget` 等隐藏模式，统一为 `idle` 内部的小动作。
- 情绪（emotion）不再作为独立渲染分支，而是状态的**修饰参数**（如 `idle + happy`）。
- 反应（reaction）取消，合并进状态 + 音频。

## 6. 情绪与表情

情绪只保留 4 种，且**必须由明确事件驱动**，不允许随机漂移。

| 情绪 | 触发 | 展示 |
| --- | --- | --- |
| `neutral` | 默认 | 平静 |
| `happy` | 单击、抚摸、专注完成、任务完成 | 笑眼 |
| `curious` | 悬停、拖入文件、收到新信息 | 歪头、眼睛放大 |
| `sleepy` | 进入休息、长时间无交互 | 半闭眼、慢动作 |

规则：

- 情绪是叠加在状态上的滤镜，不改变状态机。
- 单个情绪持续 3~6s 后自然回落到 `neutral`。
- 安静模式 `minimal` 下，情绪仍可变化，但不播放声音、不主动弹窗。

## 7. 亲密度与成长阶段

### 7.1 设计目标

把现有 5 套成长系统（情绪 / 人格 / 成长 / 属性 / 成就）**收敛为一个对用户可见的成长体系**：

- **亲密度**：唯一成长数值。
- **成长阶段**：亲密度到达阈值后，形象与语气发生变化。

### 7.2 亲密度规则

| 行为 | 亲密度 |
| --- | --- |
| 单击互动 | +1 |
| 抚摸 | +2 |
| 完成一次对话 | +3 |
| 完成一次提醒 | +4 |
| 完成一次专注 | +5 |
| 拖入文件并处理 | +3 |

约束：

- 每个自然日通过「点击 / 抚摸」获得的亲密度有上限（默认 60），避免刷分。
- 长时间不互动不掉亲密（避免负反馈）。
- 亲密度在「记录 → 关于 Piko」中以进度条 + 文案展示，不展示裸数字公式。

### 7.3 成长阶段

| 阶段 | 亲密度门槛 | 表现变化 |
| --- | --- | --- |
| 初识 | 0 | 基础形象、简短问候 |
| 熟悉 | 200 | 更丰富的待机动作、常用语解锁 |
| 默契 | 800 | 更主动的陪伴小动作、纪念日提示 |
| 老友 | 2000 | 更自然的语气、专属外观细节 |

- 阶段提升时，在精灵窗口播放一次升级动画 + 一句祝贺，并在「记录」页留一条成长记录。
- 阶段只升不降。

### 7.4 用户可见性

「记录」页顶部 + 精灵悬停菜单中可看到：

```text
Piko · 熟悉阶段
亲密度 ████████░░ 320 / 800
```

## 8. 外观风格

替代现有「换装 / Outfit + 自定义图片 + Live2D 模型」的复杂组合，收敛为 **3 种外观风格**：

| 风格 | 说明 | 默认 |
| --- | --- | --- |
| 经典像素 | 内置默认形象，所有平台可用 | ✅ |
| 动态角色 | Live2D 形象（需模型资源可用时才展示选项） | 可选 |
| 自定义图片 | 用户上传一张图片作为形象（静态） | 可选 |

规则：

- 外观选择只在「设置 → 伙伴」中，不在面板首页出现。
- Live2D 模型不可用时隐藏该选项，不展示「已禁用」列表。
- 自定义图片：限制格式（png/jpg/gif/webp）、大小 ≤ 8MB、自动裁剪为方形。
- 切换外观后立即生效并持久化，无需保存按钮。

## 9. 安静模式（打扰档位）

统一术语为 **安静模式**，三档：

| 档位 | 名称 | 行为 |
| --- | --- | --- |
| `active` | 活泼 | 有声音、有小动作、允许主动问候 |
| `balanced` | 平衡（默认） | 有声音、轻小动作、低频主动提示 |
| `minimal` | 安静 | 无声音、无主动弹窗，仅响应用户明确交互 |

- 现状中类型名为 `active | balanced | minimal`，文档与 UI 统一称为「活泼 / 平衡 / 安静」。
- `minimal` 下：不播放音频、不主动弹气泡、不做注意力脉冲；单击仍可打开对话。
- 免打扰时段（见模块 03）优先级高于安静模式：时段内等同于 `minimal`。

---

## 10. 主动行为

主动行为（如小动作、注意力脉冲、主动问候）必须**可预测、可关闭、低频率**。

| 行为 | 触发条件 | 频率上限 |
| --- | --- | --- |
| 待机小动作 | 每 20~45s 随机 | 1 次 / 20s |
| 注意力脉冲 | 无交互 > 90s（`balanced`） | 1 次 / 3min |
| 主动问候 | 用户回到电脑（空闲结束） | 1 次 / 30min |
| 休息提醒联动 | 由模块 03 触发 | 由免打扰控制 |

规则：

- `minimal` 下关闭全部主动行为。
- 全屏 / 演示模式下一律不打扰。
- 每次主动行为只做一次轻反馈（动画或一个短气泡），不做连续催促。

## 11. 快捷菜单

右键或长按打开，使用系统原生菜单（Tauri menu）而非自绘，降低维护成本：

```text
与 Piko 对话
────────────
今天
记录
────────────
休息 5 分钟
隐藏 Piko
────────────
设置
退出
```

- 菜单项随当前状态变化（如专注中显示「结束专注」）。
- 菜单最大 7 项，不加二级菜单。

### 11.1 悬停快捷操作

精灵悬停时，在精灵下方浮出 3 个圆形按钮：

| 按钮 | 动作 |
| --- | --- |
| 💬 对话 | 打开 / 收起对话窗口 |
| ☕ 休息 | 开始 5 分钟休息 |
| ⋯ 更多 | 打开快捷菜单 |

- 按钮仅在悬停或键盘聚焦时出现，离开后 1s 淡出。
- **移除**当前常驻的 `pet-actions` 底栏与精灵上的 `pet-clock`。

## 12. 反馈与提示

| 类型 | 承载 | 规则 |
| --- | --- | --- |
| 即时反馈 | 精灵动画 + 音效 | 150ms 内出现 |
| 轻提示 | 精灵头顶短气泡 | ≤ 14 字，2.5s 自动消失，可点击关闭 |
| 结构化信息 | 对话窗口 | 不经过精灵气泡 |
| 系统通知 | 系统通知中心 | 仅提醒 / 日程到点 |

禁止：

- 在精灵窗口堆叠多条气泡。
- 提示文字超过 2 行。
- 用精灵气泡展示错误码或技术信息。

## 13. 数据模型（目标态）

```ts
interface PetProfile {
  companionName: string;
  appearance: "classic" | "live2d" | "custom";
  customImagePath?: string;
  live2dModelId?: string;
  quietMode: "active" | "balanced" | "minimal";
  intimacy: number;
  stage: "new" | "familiar" | "close" | "oldFriend";
  totalInteractions: number;
  petStrokeCount: number;
  lastInteractionAt?: number;
  position: { screenId: string; x: number; y: number };
  createdAt: number;
}
```

存储：

- 权威存储：Rust 侧单一 store（替代现状 localStorage + 自定义事件）。
- 前端只读缓存，通过 `pet-profile-updated` 事件同步。

## 14. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 精灵图片加载失败 | 回落到经典像素形象，不显示破图 |
| 位置越界 | 钳制到工作区安全区 |
| 多屏拔掉 | 回落到主屏右下角 |
| Live2D 渲染崩溃 | 自动回落经典形象，并在设置页提示一次 |
| 全屏应用 | 自动隐藏，退出恢复 |
| 拖入不支持的文件 | 精灵显示「疑惑」，提示「这个文件我看不了」 |

## 15. 验收标准

- [ ] 单击打开 / 收起对话，双击休息 / 唤醒，右键打开快捷菜单。
- [ ] 抚摸与拖动不互相误判（路径 / 位移阈值全部生效）。
- [ ] 位置在重启、换屏、拔屏后都可见且合理。
- [ ] `minimal` 模式下无任何声音与主动弹窗。
- [ ] 亲密度在互动后增长并持久化，重启后保持。
- [ ] 阶段提升有可见反馈，且不下降。
- [ ] 悬停快捷操作出现 / 消失平滑，不误触。
- [ ] 全应用无精灵上的常驻时钟与常驻操作栏。
- [ ] 外观切换即时生效且重启保持。

## 16. 与现状的迁移清单

| 现状文件 / 能力 | 处理 |
| --- | --- |
| `PetWindow.tsx` | 拆分：事件归一化 / 渲染 / 菜单，移除非必要状态 |
| `InteractionManager` | 保留，补齐抚摸与拖动判定阈值 |
| `EmotionManager` / `EmotionTriggers` | 收敛为 4 情绪，事件驱动 |
| `MoodManager` | 下线（合并进情绪） |
| `PersonalityManager` / `BehaviorSystem` / `DialogueSystem` | 人格内部化，仅用于文案语气；不再独立可见 |
| `GrowthManager` / `AttributeSystem` / `AchievementSystem` / `DailyTaskSystem` | 收敛为亲密度 + 阶段 |
| `OutfitManager` / `OutfitRenderer` / `OutfitLoader` | 下线，改为外观风格 |
| `optimization/*` | 保留，仅内部使用 |
| `petAudio` | 保留，按安静模式统一开关 |
