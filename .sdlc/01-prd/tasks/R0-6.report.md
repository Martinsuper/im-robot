> 12/13/14 三处任务卡 Change 未逐条点名，同属「用户主动写操作失败」，按同一原则处理（真实原因优先，原动作文案兜底）。

**渲染层**（同一文件，非 catch 处）：

- `{error && <p className="memory-error">{error}</p>}` → `<ErrorState message={error} onRetry={...} onDismiss={() => setError("")} />`。
- 三个空态裸 `<p className="empty-state">` → `<EmptyState title=... description=... />`：
  - 记忆列表：`没有匹配的记忆` / `还没有记忆`（区分 search 与 list 视图）
  - 待确认：`没有待确认的记忆推断`
  - 反思总结：`还没有反思总结`
- **额外补的 2 处 ErrorState**：`pending` 与 `reflections` 子视图原先完全不渲染 error（而 `loadPending`/`loadSummaries` 现在会设 error），已各补一个 `ErrorState`（onRetry 分别指向 `loadPending()` / `loadSummaries()`）。否则新设的 error 无处显示。
- 空态改为 `!error && xxx.length === 0`：出错时只显示 ErrorState，不同时显示「没有记录」，避免自相矛盾。
- `handleExport` 成功分支：`setError("已复制…")` → `toast.success("已复制记忆导出到剪贴板")`。原实现把成功提示塞进 error 状态（会以红色错误条渲染），顺手修正。
