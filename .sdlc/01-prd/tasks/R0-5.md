# R0-5 任务卡 · 建立令牌层 `src/styles/`

> 由 coordinator 派发给 worker。执行前请完整阅读本文件，不要额外发挥。

## Target

`/Volumes/W_W/claude-workspace/im-robot` 的 CSS 令牌层与基础层。

## 背景（已实测，直接采信）

现状「双 CSS 互相覆盖」的真实结构是：

- `src/App.css`（2721 行）是事实主样式，包含 panel + bubble + pet + onboarding 全部规则。
- `src/features/app/design-system.css`（128 行）是后追加的**面板覆盖层 + 令牌层**，只有第 23、24 行涉及 bubble。
- 由 `src/App.tsx` 按 `App.css` → `design-system.css` 顺序引入，**后者覆盖前者**。
- 由此产生一批**死代码**：
  - `App.css:1458` 的 `.panel-shell { --panel-tint: #f4f7f4; --panel-accent: #007aff; ... }`（9 个 iOS 蓝变量）与 `App.css:1482-1483` 的 `--panel-shell--blue/--peach`，全部被 `design-system.css:15` / `:23-24` 的绿色令牌覆盖。
  - 全局 `:focus-visible` 写了两遍：`design-system.css:12` 与 `App.css:1498-1501`。

## Change

### 1. 新建 `src/styles/tokens.css`

- 把 `design-system.css:2-8` 的 `--piko-*` 六个令牌搬过来，**值不变**。
- 新增 `--piko-fill: #fffefa;`（`src/components/feedback/feedback.css` 已引用它，目前只能走字面量兜底）。
- 把 `--panel-*` 语义令牌集中定义到**唯一一处**（建议 `:root`），值取 `design-system.css:15-22` 的现行生效值，不要取 App.css 里那份被覆盖的 iOS 蓝。
- 补最小可用的间距 / 圆角 / 字号 / 层级令牌，够 R1 用即可，不要设计一整套。

### 2. 新建 `src/styles/base.css`

收敛现在重复的基础规则：

- `-webkit-tap-highlight-color`（`design-system.css:10`）
- `button svg`（`design-system.css:11`）
- `:focus-visible` —— 合并 `design-system.css:12` 与 `App.css:1498-1501` 为一处全局规则

### 3. 修改 `src/App.tsx`

引入顺序改为：`tokens.css` → `base.css` → `App.css` → `design-system.css`。

### 4. 删除死代码（只删被覆盖的那几行，别扩大范围）

- `src/App.css`：删除 `:1458-1467` 的 `--panel-*` 变量声明（**保留 `.panel-shell` 的布局属性**：`height` / `display` / `grid-template-columns` 等）、`:1482-1483` 的 `--panel-shell--blue/--peach` 变量行、`:1498-1501` 的重复 `:focus-visible`。
- `src/features/app/design-system.css`：删除已迁走的 `:root` 令牌块与 `:10-12` 的基础规则，其余保留。

- **不做** `App.css` 里重复选择器的清洗（同属 R5）。
- 不要改任何 `.tsx` 组件逻辑（`App.tsx` 只允许改 import 段）。
- 不要改 `src/components/feedback/feedback.css`（coordinator 的产物，只需在 tokens.css 里提供 `--piko-fill` 即可满足它）。
- 不要运行 `npm run build` 或 `npm run test:e2e`（会与其他 worker 抢 `dist/` 和 `127.0.0.1:4173`）。
