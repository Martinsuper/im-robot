# 模块 05 · 设置与个性化

> 关联：[00-产品总览与设计原则](./00-产品总览与设计原则.md) · [02-模块-AI对话与助手](./02-模块-AI对话与助手.md) · [06-模块-系统集成·权限·插件](./06-模块-系统集成·权限·插件.md)
> 代码位置（现状）：`PanelWindow.tsx` settings 部分、`src/features/onboarding/OnboardingWindow.tsx`

---

## 1. 模块目标

让设置在 30 秒内改完想改的东西：

- **分组清晰**：按用户会说的话分组，而不是按技术模块。
- **即时保存**：改了就生效，没有「保存」按钮。
- **默认合理**：大多数用户不需要进设置。
- **技术隐藏**：高级参数折叠，普通用户永远看不到 Base URL。

---

## 2. 现状问题

- 设置分散在 4 个 section：个性化与系统、互动活泼度、休息提醒、模型服务、HTML 预览（5 个），互不相邻；
- 每个 section 有自己的「保存」按钮，容易漏存、状态不一致；
- 模型服务里同时塞了服务类型、Base URL、Model、语速模型下载、API Key、Temperature、超时；
- 引导页只问名字和 AI 服务，不问语言、不问打扰偏好，且用的是独立的 provider 列表（与面板不一致）；
- 主题只有 3 个色值，但精灵外观又有一套独立选择；
- 没有语言切换入口，但代码里有 i18n。

## 3. 引导（Onboarding）

### 3.1 目标

首次启动 3 步内可用，且 **可以完全跳过**。

### 3.2 流程

```text
步骤 1 / 3  欢迎 + 给 Piko 起名
            [ 名字输入框（默认 Piko）]
            [ 继续 ]   [ 以后再说 ]

步骤 2 / 3  连接 AI（可跳过）
            选择服务： [ OpenAI Compatible ▼ ]（预置常用）
            API Key： [ ............ ]
            [ 测试连接 ]  →  成功/失败
            [ 完成 ]   [ 跳过，先用本地的 ]

步骤 3 / 3  认识一下
            ✔ 点击 Piko 就能聊天
            ✔ 拖文件给它可以帮你读
            ✔ 说「提醒我…」它会记住
            [ 开始使用 ]
```

### 3.3 规则

- 任何一步都可跳过；跳过时使用合理默认（本地模型探测或稍后配置）。
- 不出现 Base URL / Model / Temperature。
- 引导只运行一次；「设置 → 关于」中提供「重新运行引导」。
- 引导使用统一的 provider 预设（与设置页共用同一份配置常量）。
- 引导完成后直接打开对话窗口空状态，让用户立刻体验价值。

### 3.4 引导触发条件

- 首次安装。
- 用户手动「重新运行引导」。
- 引导版本升级且新增关键项时（可选，需谨慎）。

## 4. 设置分组

「设置」Tab 分 5 组，均为折叠卡片或分组区块：

```text
设置 Settings
├─ 1. 伙伴
│     名字、外观风格、安静模式、精灵显示开关
├─ 2. 对话与模型
│     服务、API Key、[测试连接]、▸ 高级设置
├─ 3. 提醒与免打扰
│     免打扰时段、休息提醒、专注时免打扰、通知开关
├─ 4. 系统与隐私
│     开机启动、全局快捷键、托盘行为、Piko 主动记住、数据导出/清空
└─ 5. 关于
│     版本、检查更新、重新运行引导、开源许可、权限状态
└─ 6. 高级（默认折叠，位于最底部）
      模型参数、语音模型、实验室（HTML 预览）、外部插件
```

### 4.1 伙伴

| 项 | 控件 | 说明 |
| --- | --- | --- |
| 名字 | 文本 | ≤ 16 字 |
| 外观风格 | 三选一 | 经典像素 / 动态角色 / 自定义图片 |
| 自定义图片 | 上传 | 仅选「自定义图片」时出现 |
| 安静模式 | 分段控件 | 活泼 / 平衡 / 安静 |
| 显示 Piko | 开关 | 等同托盘显示/隐藏 |

### 4.2 对话与模型

- 服务选择（预置列表）+ API Key + 测试连接。
- 「本地服务」无需 Key，自动探测。
- ▸ 高级设置：Base URL、Model、Temperature、超时、语音模型下载。
- 连接状态用三态徽标：未配置 / 已连接（模型名）/ 连接失败（原因）。

### 4.3 提醒与免打扰

- 免打扰时段开关 + 起止时间。
- 休息提醒开关 + 间隔 + 冷却。
- 专注时是否免打扰。
- 通知权限状态 + 「去开启」。

### 4.4 系统与隐私

| 项 | 控件 |
| --- | --- |
| 开机自动启动 | 开关 |
| 全局快捷键 | 展示当前快捷键 + 可修改（可选） |
| 点击 Piko 时 | 切换对话 / 只做动画（可选） |
| Piko 可以主动记住 | 开关 |
| 导出我的数据 | 按钮 |
| 清空我的数据 | 危险按钮（二次确认） |

### 4.5 关于

- 版本号、更新状态、检查更新。
- 重新运行引导。
- 权限状态（通知 / 屏幕录制 / 文件）——见模块 06。
- 开源许可与素材来源说明。

### 4.6 高级

- 模型高级参数。
- 语音模型管理。
- HTML 预览（实验室）。
- 外部插件列表（无插件时不显示入口）。

## 5. 即时保存

- 所有设置项修改后立即写入 Rust store，并广播 `settings-updated` 事件。
- 无需「保存」按钮。
- 失败时：控件回滚 + Toast 提示「保存失败，请重试」。
- 每个分组提供「恢复默认」链接（仅作用于该组）。

---

## 6. 主题与视觉

现状：主题只有 3 个色值，且与精灵外观分离。

目标态：

- 主题收敛为 **浅色 / 深色 / 跟随系统**（更符合现代桌面应用预期）。
- 强调色（accent）作为可选项，提供 3~5 个预设。
- 精灵外观与主题解耦（外观在「伙伴」组）。
- 主题切换即时生效，持久化。

> 若短期不实现深色，则至少把「鼠尾草绿 / 湖水蓝 / 暖桃色」合并为「强调色」选项，并把主题命名说清楚。

---

## 7. 语言

现状：已接入 i18n（zh-CN / en-US / ja-JP），但只有引导页使用，且无切换入口。

目标态二选一（需产品决策）：

| 方案 | 说明 | 建议 |
| --- | --- | --- |
| A. 完整多语言 | 全量抽取文案，设置中提供语言切换，三种语言可用 | 长期目标 |
| B. 只做中文 | 移除未使用的 i18n 依赖与语言文件，避免半成品 | 短期推荐 |

**决策建议**：R0~R4 采用方案 B（只做中文、清理 i18n），R5 再评估方案 A。理由：未完成的 i18n 会造成维护负担与不一致体验。

若采用方案 B，需删除或隔离 `I18nProvider`、`src/locales/*`，并统一文案常量。

## 8. 设置数据结构（目标态）

```ts
interface Settings {
  companion: {
    name: string;
    appearance: "classic" | "live2d" | "custom";
    customImagePath?: string;
    quietMode: "active" | "balanced" | "minimal";
    petVisible: boolean;
  };
  ai: {
    provider: string;
    apiKey?: string;
    baseUrl: string;
    model: string;
    temperature: number;
    timeoutSeconds: number;
    speechModel: string;
  };
  notify: {
    dndEnabled: boolean;
    dndStart: string;
    dndEnd: string;
    breakReminderEnabled: boolean;
    breakIntervalMinutes: number;
    breakCooldownMinutes: number;
    quietDuringFocus: boolean;
  };
  system: {
    autostart: boolean;
    globalShortcut: string;
    clickBehavior: "toggle_chat" | "animate_only";
    memoryCaptureEnabled: boolean;
  };
  appearance: {
    theme: "light" | "dark" | "system";
    accent: string;
  };
  advanced: {
    htmlPreviewEnabled: boolean;
  };
}
```

## 9. 验收标准

- [ ] 引导 3 步内完成，可完全跳过，无技术字段。
- [ ] 设置分 5 个主分组 + 1 个高级组，符合用户语言。
- [ ] 所有设置即时保存，无「保存」按钮，失败有回滚提示。
- [ ] 模型高级参数默认折叠。
- [ ] 主题 / 外观 / 安静模式分区正确，互不混淆。
- [ ] 高级组默认折叠且位于底部。
- [ ] 语言策略明确（要么完整支持，要么清理）。
- [ ] 重新运行引导可用。
